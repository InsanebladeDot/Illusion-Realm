# 提示词资料库组件复用与画师库

本轮将角色、画师、动作、背景、表情的卡片统一为实际共用组件。不是复制角色卡片的样式到每个库，而是各自将源数据映射为相同展示参数。

## 复用边界

| 组件 | 共用能力 |
| --- | --- |
| `LibraryCard` | 4:5 预览、名称、可选副标题、分类徽标、指标、选中标记、可选收藏和详情 |
| `LibraryPickerToolbar` | 搜索、排序配置、多选、复制、只看已选、清空、显示方式插槽 |
| `LibrarySidebar` | 侧栏宽度、主题背景、边界、滚动容器 |
| `LibraryResults` | 主区留白、内部滚动、固定分页位置 |

角色仍由 `CharacterCard` 适配资料；其他库由 `TagLibraryCard` 适配。角色详情、触发词与描述词应用、各库多选、分页和原有分类行为继续由业务父组件管理。新增静态库应注册数据和词条，复用 `TagLibraryDialog`，不要复制整个弹窗。

所有共用表面使用 `background`、`muted`、`foreground`、`border` 与强调色变量；文字模式、空态、输入框与底部分页也跟随主题。

## 画师库

- 40,600 条本地元数据，名称、作品数和独特性分数保留源值。
- 按名称搜索；作品数升降序、独特性升降序、名称升降序、随机共七种排序。
- 侧栏为全部、默认收藏、自定义收藏组；没有凭空增加画风分类。
- 随机顺序在当前种子下保持稳定，翻页不会反复洗牌。
- 收藏与分组保存到统一用户文档的 `artistLibrary` 段，包含独立 `version: 1`。
- 加入组会同时收藏；移出或删除组保留默认收藏；取消收藏则清理各组成员关系。
- “只看已选”独立于名称搜索和分组，应用时返回原始画师标签。
- 预览按原工具地址规则在线加载；网络失败显示无预览，仍可选择和应用。本地没有打包图片。

## 验证与边界

`node scripts/verify-artist-library.js` 执行实际查询器和 Zustand 持久化逻辑，验证数据数量、七种排序、无结果、跨页成员、已选独立性、预览映射与收藏分组生命周期；仅用户存储适配器替换为内存。

`LIBRARY_REUSE_ONLY=1` 的 `scripts/smoke-prompt-assembly.js` 专项通过真实页面入口验证四个静态库的共用结构与深浅主题计算颜色，并通过临时用户 JSON 和页面重新加载验证画师收藏恢复。图片使用离线夹具，未验证在线预览可达性或真实生成效果。

主题专项启用软件渲染和减少动效，验证配色与交互，不代表默认主题切换动画的已有停顿问题已解决。角色详情、多选与背景筛选另由原有专项回归。

注释统计以本轮开始时的源文件快照为基线，新增文件全量、修改文件按变更及直接关联说明统计；用 TypeScript 注释范围识别 JSX 和普通注释，排除词条及纯 JSON 数据。业务为 601 条有效注释 / 243 条代码（71.21%），测试为 218 / 78（73.65%）。例如：以“相框与照片”说明展示容器与源数据边界，以“通讯录分组只记联系人编号”说明收藏关系不复制完整元数据。
