# 视频、漫画与媒体工具

用户希望在桌面端完成轻量剪辑、合成、漫画对白与媒体检查，相关结果可以带回创作和画布。

- 视频编辑工作区包含素材、节目预览、检查器与多轨时间线。分割和修剪保留源边界，变换、关键帧、波形及音量变化按项目时间显示，最终通过 FFmpeg 导出。
- 视频合成与导演台保留各自的工程素材归属。视频超分应明确关联输入、拆帧及输出，保留原视频以供对照。
- 漫画对白支持编号、文字、字体、缩放、旋转和图片导出。分镜规格记录独立的页面、角色连续性、版式和项目数据需求。

## 视频剪辑验收范围

- 素材时间与项目时间分别计算。空隙、重叠、裁剪边界和音画链接应在预览、时间线和导出里保持同一解释。
- 素材查看与节目预览各自维护选中状态。窄窗优先保留预览和操作区，辅助区域按现有布局收起或滚动。
- 工程保存素材来源、片段范围、变换及轨道顺序。导出校验输出位置、覆盖确认、进度、取消和失败恢复。

## 漫画分镜需求

对白编辑器负责气泡和图片导出。分镜工作台规格另包含项目、页面、画格、角色与素材引用。按景别、视角、构图、镜头方向分别组织分镜描述，项目默认值可被单格覆盖。切格、合并、跨格叠放和同图切片应保留布局身份、阅读顺序及源图引用。项目文件版本化保存，生成快照保留当时的参数以便复现。
