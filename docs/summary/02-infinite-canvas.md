# 02 无限画布与工程素材

## 用户需求

在一张画布内组织文本、图片、视频和音频，直接从节点生成素材，保存后可以继续创作，也能跨工程复用素材。

## 已做工作

- 提供媒体节点、文本分类、便签、标注、节点网预览和画布工程导入导出。预览支持缩放、拖动及媒体信息查看。
- 图片、视频、音频节点复用创建页的表单、参考编辑和队列。结果写入工程目录后回填节点，删除节点时取消其任务。MiniMax 按媒体类型生成编号标记并兼容旧草稿。
- 工程素材与全局素材库支持批量导入和 `@` 引用。有项目依赖的素材受保护，归属未知的文件原位保留。

## 成效与待验

- 工程重开可恢复草稿和受管素材。`logs/smoke-runs.log` 记录 2026-11-18 素材存储 **9/9**，2026-11-23 画布专项 **24/24**。同日较早的 **152/166** 记录了预览按钮位置失败，后续专项覆盖范围不同，完整画布仍需复核。
- 历史验证覆盖了 HTTP 生成夹具下的请求、排队、落盘和回填。真实 GPU 的画质、音质、速度及模型组合兼容性待实机验收。
