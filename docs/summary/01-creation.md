# 01 创作流程与提示词

## 用户需求

在一个界面完成提示词整理、模型选择、图片生成和二创，从历史图片继续调整，无需手工抄参数。宽窄窗口都能打开资源和工具。

## 已做工作

- 创建页按主区实际宽度切换一、二、三栏。窄窗的资源和工具在主区打开，关闭后回到原草稿。
- 提示词支持分类、手动排序、快捷词、翻译历史和参考素材。生成区支持自定义尺寸、蒙版编辑与图像倍率，扩展选择沿用本地模型库。
- ComfyUI 图片任务串行执行，可取消排队或停止生成。历史支持排序、批量改名、移动和收藏，带生成参数的 PNG 可回填创建页。

## 成效与待验

- 常用素材可以直接加入草稿，生成结果可以从历史回到创作流程。队列停止、断连和保留已保存文件的行为见 [生成任务生命周期](../comfy-generation-lifecycle.md)。
- `logs/smoke-runs.log` 记录 2026-11-11 提示词组装专项 **20/20**。2026-11-21 Anima 预设弹框居中断言失败（**22/23**），2026-11-23 `create-layout` 进程退出 **1**（已记录断言 **2/2**，日志未给出失败原因）。两项均待复核。
