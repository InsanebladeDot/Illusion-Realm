# 05 桌面体验、数据与交付验证

## 用户需求

安装和维护更省事，登录、个人页和设置布局一致。日常创作记录要能恢复，更新后保留设置和首帧语言。

## 已做工作

- 调整标题栏、导航、登录、个人页和设置，提供独立 Windows Setup、依赖清单、下载状态和窗口历史。
- 生成小票、画布草稿、快捷词迁入 SQLite，迁移先备份、事务写入并反读核对。设置和偏好继续由用户 JSON 管理，下载恢复队列用独立 SQLite 文件。
- 创建页按需加载工具，优化模型扫描、媒体预览、视频波形和 3D 绘制。旧版构建测量中，`/create` 直接脚本从 **6.51 MiB** 降到 **2.57 MiB**（**60.61%**）。实机启动耗时未测。参见 [测量原始数据](../performance-optimization-2026-11-06/measurements.json)。
