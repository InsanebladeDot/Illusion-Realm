# 04 Agent、模型与下载

## 用户需求

可从多个供应商挑选模型，按图片输入能力和费用过滤，也能在应用内查找、下载和管理本地模型。

## 已做工作

- Agent 和提示词转译共用模型目录与选择组件，按能力限制图片输入，并提供价格排序、模型选中确认、引用保护和流式回答。Electron 按需启动 Python 子进程，供应商密钥走专用存储。
- 本地模型库支持目录浏览、分类、封面补全、LoRA 触发词和 SHA256 匹配。安装清单按工作流分组，下载队列支持重试、移除和恢复，依赖齐备后解锁对应能力。

## 成效与待验

- `logs/smoke-runs.log` 记录 2026-11-17 图片能力 **15/15**，2026-11-18 供应商专项 **9/9**，2026-11-20 下载界面 **12/12**，2026-11-23 提示词助手 **194/194**。助手同日早先曾等待编辑入口超时，后续完整专项通过。
- 大权重完整下载、真实供应商账户和模型限额仍待实测。模型与 Agent 契约见 [Agent 接入说明](../agent-integration.md)及[本地模型查询契约](../agent-model-catalog.md)。
