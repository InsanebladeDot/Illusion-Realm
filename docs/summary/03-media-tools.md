# 03 视频、漫画与媒体工具

## 用户需求

在桌面端完成轻量视频剪辑、多轨预览和导出，也能为漫画加对白、准备分镜和检查媒体参数。

## 已做工作

- 视频编辑提供素材区、节目预览、属性检查和多轨时间线，支持分割、修剪、片段变换、关键帧和音频波形。FFmpeg 执行探测、剪切、拼接和导出。
- 视频合成及导演台沿用各自的资源范围，并与画布衔接。视频超分接入 SeedVR2，补充帧拆分、批次和输出识别逻辑。
- 漫画对话框支持编号、文字编辑、缩放、旋转、字体和图片导出。保留 EXIF、分格和分镜相关文档。

## 成效与待验

- `logs/smoke-runs.log` 记录 2026-11-04 漫画对白 **54/54**、2026-11-05 编辑器 UI **139/139**、2026-11-08 真实媒体导入与时间线演示专项 **42/42**、2026-11-10 视频合成 **21/21**。
- 长素材和多轨输出、不同编码的音画同步、SeedVR2 的真实 GPU 画质仍需按实机素材验收。剪辑和分镜的详细要求见 [视频编辑器规格](../requirements/lightweight-video-editor-v1.1.md)及[漫画分镜规格](../comic-storyboard-requirements.md)。
