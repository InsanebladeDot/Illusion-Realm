# 无限画布与工程素材

用户希望在画布上组织文本、图片、视频与音频，从节点直接生成素材，重开工程后继续创作。

- 工程导入、导出和恢复应保留节点、连线、便签、标注及媒体引用。节点网提供缩略导航、媒体信息、拖动和缩放。
- 图片、视频及音频节点复用创作页面板和队列。节点独立维护草稿和任务状态，结果落盘后回填原节点。节点删除时取消其任务，并拒绝迟到结果回填。
- 工程素材和全局素材库支持批量导入与 `@` 引用。MiniMax 引用按图片、视频、音频分别编号，旧草稿仍能打开。
- 项目仍引用的素材须受到保护。受管素材按归属清理，外部或未知归属文件留在原处。草稿持久化遵循 [SQLite 迁移与恢复约束](05-desktop-and-delivery.md#数据归属与恢复)。

## 工程与任务边界

- 工程资源与全局素材分开登记。移除受管文件前核对当前草稿和其他工程引用。
- 节点参数、参考顺序和任务身份随提交记录。生成恢复后依据调用身份回填同一个仍存在的节点。
- 内嵌导演台和视频合成器保留各自的版本化文档。数据库内记录资源关联和路径，媒体文件继续由工程管理。
