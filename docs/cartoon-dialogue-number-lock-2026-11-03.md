# 漫画对话框数字双击编辑补充记录

用户澄清：右侧数字框也需双击才能输入。本次只补齐这一交互，保留已完成的淡细选框、正文双击、顶部旋转、四角缩放与离线字体。

## 实现与复用

- 六项数字：字号、行高、字距、宽度、旋转、透明度，默认只读；单击仍可聚焦、查看和复制。双击只解锁当前字段，F2提供键盘入口。
- 有效Enter提交并锁回；Escape取消草稿并锁回；失焦执行原校验并锁回。非法Enter保留编辑和就近错误，非法失焦保留错误草稿，不能伪造成功或强制夹值。
- 原有EditorFloatField增加可选editActivation和调用方翻译后的activationHint，草稿、范围、精度和提交仍维护一份。漫画六项通过FIELDS统一传参，视频编辑器不传策略，保留直接输入。
- 编辑许可属于每个字段实例，不写作品历史。图层切换由原key重建字段；撤销和画布手柄改变实际参数，依旧回流显示，不自动解锁输入。
- 修改公共数字控件、漫画属性接入、两语言提示、画布过时注释及漫画回归脚本；未新增IPC或持久化契约。
