# 图片生成的停止与断连处理

本应用的图片队列按 FIFO 串行执行。单个任务可生成多张图片，每张完成下载和保存后再处理下一张。
任务参数与输出目录在提交时冻结；切换页面不会取消任务。

## 用户操作

- 排队任务提供「取消排队」，只撤回本应用尚未提交的任务。
- 运行任务提供「停止生成」，进入「正在停止」，主进程撤回服务端队列中的对应任务，
  核对运行任务后向 `/interrupt` 发送停止请求，并等待 `/queue` 确认该任务不再运行或排队。
- 「停止全部」先撤回本应用所有待执行任务，再停止当前任务。不会清空整个 ComfyUI 队列。
- 任务停止或失败后，已经保存的图片、完成张数及「查看图片」入口保留。
- 停止期间正在保存的一张图片允许保存完成，不回滚或删除已写入文件。

## 服务异常

每次生成提交、历史查询和下载都有请求超时（8 秒，覆盖响应体读取）；历史轮询间隔 800ms，
等待生成整体上限 10 分钟。工作流执行失败与连接断开使用不同的 IPC 错误码。

连接断开或等待超时：当前任务失败，待执行任务终止，避免持续向不可用服务提交。
用户检查服务后可手动重新提交。普通工作流错误只使当前任务失败，下一项继续执行。
服务端拒绝停止或无法确认停止时，显示失败原因并终止待执行任务，不声称服务端已停止。

## 边界

- ComfyUI 是外部服务，客户端无法在连接断开时保证远端任务已终止；应检查服务端队列。
- 提交尚未返回时的主动停止会等待任务 ID，再撤回/中断；提交超时而未获得 ID 时提示停止未确认。
- 中断前核对远端正在运行的 ID；部分旧 ComfyUI 的 `/interrupt` 是全局操作，核对和中断并非
  服务端原子操作，共享服务的其它客户端应避免在此时更换运行任务。
- 取消请求按发起窗口和客户端请求 ID 隔离。前端不能提供任意服务地址或其它窗口的任务 ID 来停止。
- 本次任务面板与队列取消针对图片生成；视频仍共用有界的生成代理，但未接入图片任务面板。
- 队列不落盘，应用重启后不恢复。

## 验证

`node scripts/verify-comfy-generation.js` 用真实本地 HTTP 服务模拟 ComfyUI，覆盖成功、
提交/轮询/下载阶段错误、无响应、取消提交中/排队/运行/下载任务、停止拒绝、延迟确认与窗口隔离。
测试不运行模型、不调用真实生成服务。

重建 Next 静态导出后，单独运行 `electron scripts/smoke-generation-notice.js`，验证真实页面的
取消排队、停止当前、停止全部、部分完成保留、断连终止后续提交，以及手动重新提交。
页面冒烟使用模拟 IPC；与前述真实 HTTP 测试配合验证边界，不代替真实 GPU 推理测试。
