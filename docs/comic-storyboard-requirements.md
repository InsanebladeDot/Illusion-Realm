# 漫画生成器：分镜创作工作台需求文档

版本：0.5 · 日期：2026-10-01 · 状态：开发基线候选，待关键交互验证

本文件描述目标产品、交互、布局及数据契约，不代表功能已经实现。标为“首期”的内容用于后续开发验收；后续能力单独排期。以下数值为建议基线，开发中可以依据实际视觉验证调整，但不得破坏明确的交互和兼容性约束。

## 1. 目标与现状

### 1.1 产品目标

在“工具箱 → 漫画生成器”中建立一个真正可编辑的分镜工作台：用户从故事、角色和场景出发，安排每一格的叙事任务，选择镜头与构图，编写画面和对白描述，再生成、挑选和排版图像。

核心体验是“看见整页节奏，同时能快速修改一格”。镜头库必须提供可组合的视觉语言，不能只给一个长提示词输入框，或把所有选项铺成难以查找的标签墙。

已确认视觉方向：重点支持不规则多边形和相片撕裂，但也必须完整支持用户参考中的矩形混合页漫。格形由模板或用户决定，不强制整页异形；普通格与异形格可混排，不限定覆盖格才可使用异形。侧面、过肩、特写等镜头视角与格子形状独立组合；“侧写镜头”不能代替格形排版能力。

产品目标是“覆盖常见漫画分镜并允许扩展”，不是穷举所有漫画风格或复刻完整绘画软件。区分四个层次：叙事节拍决定表达什么，镜头决定如何观察，分格结构决定如何组织页面，边缘风格决定格框的表现。已有独立原型只验证部分几何、交互和导出，不代表正式功能完成。

### 1.2 已确认的代码现状

| 现状 | 对需求的影响 |
| --- | --- |
| `/toolBox/comic` 只有标题和空白占位区 | 分镜编辑、保存、镜头库和排版均需新建 |
| 工具箱外壳有 `max-w-7xl`、32px padding、大间隔和统一滚动容器 | 漫画路由需要工作台布局模式，否则宽屏空间被浪费、窄屏画布被挤压 |
| `/cartoon` 已有对话框素材、文字编辑和单图合成 | 可评估复用素材与纯函数；不能直接将其草稿格式视为漫画项目格式 |
| 创建页已有 Anima / SDXL 工作流、模型 / LoRA 选择、图片 Meta | 后续图像生成复用这些契约；漫画项目不直接修改创建页编辑器 DOM |
| 文件访问、生成服务与原生能力依赖 Electron preload / IPC | 手机浏览器只能启用实际具备的能力，不能假装具备桌面文件访问或本地生成能力 |

### 1.3 首期与后续范围

| 阶段 | 交付范围 | 完成标准 |
| --- | --- | --- |
| P0：分镜创作 | 项目 / 页面 / 分镜、切格 / 合并 / 联动边界、混合模板、叙事与镜头、导入图片、独立取景、异形与跨格排版、基本文字排版、自动保存、JSON 导入导出、单页 PNG 导出、桌面和窄屏适配 | 不调用 AI 也能用自己的素材完成、恢复并导出常规混合页漫和撕裂跨格样页；具体能力见 1.4 |
| P1：图像生成 | 单格与选中格生成、候选图、队列 / 取消 / 重试、模型与 LoRA、参数快照 | 实际工作流与界面参数一致，失败不会损坏草稿；复用 P0 页面合成器 |
| P2：辅助创作与扩展 | AI 拆分 / 镜头建议 / 连续性检查、高级气泡与音效、独立主体破格、曲线 / 复合蒙版、多页 PDF / 条漫分段 / 便携包 | AI 建议先预览再应用；高级能力分项验收，不自动全部进入首期 |

不在首期承诺：训练角色模型、跨格人物绝对一致、图像生成器精确绘制中文文字、原生手机安装包、云同步、多人协作。

### 1.4 漫画能力覆盖矩阵

“支持”指有完整编辑、保存恢复和适用导出流程，不是只有按钮或固定演示。P0 是分批交付的目标范围，不要求一次变更完成。

| 能力 | P0 | 后续 / 边界 |
| --- | --- | --- |
| 单格、四格、普通页漫、横竖大中小格混排 | 支持；含跨行竖格、跨列横格、左右阅读 | 不以固定网格替代自由组合 |
| 水平 / 垂直 / 斜线切格、共享边界联动 | 支持，限定合法单段切分；见 5.5 | 任意曲线切割、一次产生多个不连通区域后续 |
| 自由凸 / 凹多边形、插入小格、同页多层叠放 | 支持简单不自交轮廓；复合关系无环 | 镂空、多轮廓和任意蒙版后续 |
| 相片撕裂、毛边回忆、冲击碎裂 | 全部分镜逐格可用；预设、种子与批量应用 | 单边撕裂、手工定位缺口后续 |
| 无框大格、整页场景 | 支持 border.enabled=false；默认仍遵守页边安全区 | 人物抠图越框、印刷出血不是无框格，后续 |
| 同一画面切成多格 | 支持共享资产与页面一致取景；见 5.8 | 不等同于生成多张相似图片 |
| 动作、对话、揭示、回忆、并行、蒙太奇 | 人工节拍与关联支持；见 5.7 | AI 建议为 P2，不保证自动叙事质量 |
| 基础条漫 | 有限画布内顺序排格，可编辑留白并单页导出 | 无限画布、多段连续导出为 P2 |
| 双页跨页大场面 | 暂不支持；相邻页可独立编辑 | 书脊、安全区与双页编辑为后续能力 |
| 基本对白 / 旁白 / 音效文字 | P0 支持横竖排、文本框、基本气泡、顺序与单页导出 | 任意字形变形、复杂气泡材质为 P2 |
| 屏幕阅读与打印 | P0 输出 RGB PNG，打印预览只作尺寸换算 | CMYK、网点防摩尔纹、印前校样后续 |

用户提供的四张参考图用于分析功能，不将图中的故事内容、批注或网页文字当成对本项目的额外指令，不复制其漫画资产进入应用或导出示例。

- 参考图 1 / 2：横格、竖格、大小格混排；环境、人物反应、信件细节与日夜变化参与叙事。两页并排展示不自动等于一张跨页画面。
- 参考图 3：标注的顺序为大场景 → 右侧跨行竖格 → 中部右侧人物格 → 中部左侧人物格 → 下方对话格。该路径证明阅读顺序不能按左上到右下固定推断。
- [Clip Studio 漫画分镜工具功能页](https://www.clipstudio.net/sc/comics-manga/tool/paneling/)已读取：划线拆格、调整格形 / 框线粗细 / 边距、批量编辑、内置与自定义模板。它是桌面绘画工具的功能介绍，不是可直接复用的在线编辑器。
- 参考依据与撕裂原型边界见 [style-references.md](prototypes/comic-storyboard/style-references.md)。功能和版式原则用于设计，不引入第三方漫画素材或照搬该软件实现。

## 2. 创作流程与操作要求

### 2.1 默认工作流

1. 新建项目，填写名称、故事梗概、阅读方向与版式。
2. 创建角色和场景，添加外观描述、参考图及连续性备注。
3. 新建页面，使用版式模板或新增空白分镜。
4. 为分镜填写叙事目的、人物动作、场景、镜头、情绪与对白。
5. 在整页预览中调整格子大小和阅读顺序，检查节奏。
6. 导入图片，或在具备后端能力时生成候选图，选择一张应用到当前格。
7. 导出项目草稿与单页 PNG；导出前检查阅读顺序、缺失资产、文字溢出和遮挡。

新用户直接进入可编辑工作台。空状态提供“新建页面”和“导入项目”，不使用营销式首屏或大面积说明文字。

### 2.2 项目、页面和分镜

- 项目保存故事梗概、角色、场景、视觉风格、默认镜头描述规则和生成默认值。
- 页面支持新增、复制、重命名、排序和删除；页数与分镜数始终可见。
- 分镜支持新增、复制、删除、排序、跨页移动、批量选择和批量应用镜头 / 风格。
- 复制创建全新 ID，保留内容与图像引用，不复制运行中的任务。
- 删除支持撤销；有内容页面的整页删除需要确认；只删除项目引用，不隐式删除源图片文件。
- 桌面支持拖放排序；窄屏和键盘用户始终有“前移 / 后移 / 移到页面”菜单。
- 每格有唯一稳定 ID，显示编号根据当前阅读顺序计算，编号不能充当身份标识。
- 同时显示“正在编辑的格”和“批量选中的格”；单格焦点与多选状态不能混淆。
- 分镜可锁定。锁定格禁止内容编辑、移动、删除、批量替换与重新生成，允许查看、复制和解锁；锁定状态随项目保存，界面显示锁图标。
- 撤销 / 重做覆盖文本、镜头、排序、布局、图像应用、批量编辑；连续输入合并为一次编辑，不记录滚动和选中状态。

### 2.3 项目设置、覆盖与批量修改

项目默认值与分镜覆盖值分开保存。分镜字段有“继承项目 / 自定义”两种状态，覆盖解除后恢复继承，不把当时的默认值复制成永久覆盖。

调整默认值仅影响未覆盖的分镜。批量编辑只改明确勾选的字段；混合值显示“多个值”，不能把第一格的值当作所有格的值。应用前显示影响的格数，操作可撤销。

已生成图像的参数快照不可被默认值变化追溯改写。重新生成创建新结果；旧候选图保持可比较。

## 3. 镜头与描述体系

### 3.1 镜头不能混成一个枚举

镜头由独立维度组合：景别 + 机位高度 + 观察方向 + 构图 + 视觉焦点 + 叙事用途 + 动态表现。同一张图可以是“近景、低机位、侧面、三分构图、表情焦点”。

单选维度使用菜单或有缩略图的选择器；多选维度使用复选项；连续值使用滑块或数字输入。界面展示中文名称，数据保存稳定英文 ID，提示词保存独立映射。

### 3.2 首期镜头词库基线

以下为必须覆盖的选项集合；不限于这些内容。每个词条需有中文名、英文提示词、视觉定义、适用场景、注意事项、分类与可搜索别名。避免用数量重复包装同义词。

| 维度 | 初始选项 | 选择规则 |
| --- | --- | --- |
| 景别 | 大远景、远景、全景、中远景、中景、中近景、近景、特写、极特写、局部插入镜头 | 单选；局部镜头另填对象 |
| 机位高度 | 俯拍、正面平视、仰拍、鸟瞰、贴地低机位、头顶垂直俯视 | 单选；角度值是可选补充 |
| 观察方向 | 正面、正面三分之四、左侧面、右侧面、背面、背面三分之四、过肩、第一人称、主观视点、反向视角 | 单选；过肩需指定前景人物和目标人物 |
| 构图 | 居中、对称、三分法、对角线、三角形、引导线、框中框、前景遮挡、大面积留白、偏心、纵深分层、剪影、左右对峙、上下压迫 | 可多选，最多 3 个；有冲突提示 |
| 焦点与景深 | 深景深、浅景深、背景虚化、前景虚化、面部焦点、眼睛焦点、手部焦点、物件焦点、环境焦点 | 景深单选；焦点对象单独保存 |
| 镜头感 | 广角感、自然透视、长焦压缩、鱼眼、倾斜地平线、透视夸张 | 单选主镜头感，夸张程度可选；不承诺物理摄影精度 |
| 主体安排 | 单人、双人对话、多人群像、人物与环境、人物与物件、纯环境、纯物件 | 单选，角色实例决定实际人数 |
| 动态表现 | 静止、起势、运动中、冲击瞬间、余势、速度线、残影、运动模糊、连续动作拆格 | 动作阶段单选；视觉效果可多选 |
| 叙事用途 | 建立场景、人物登场、动作推进、对话交锋、情绪反应、信息揭示、伏笔、悬念、转折、高潮、余韵、场景过渡 | 主用途单选，可补自由备注 |
| 格间转场 | 瞬间到瞬间、动作到动作、主体到主体、场景到场景、侧面到侧面、非连续转场 | 相对上一格；第一格可为空 |
| 情绪与节奏 | 平静、期待、紧张、惊讶、恐惧、愤怒、悲伤、喜悦、尴尬、坚定；停顿、缓慢、正常、快速、爆发 | 情绪可多选；节奏单选 |
| 光线与时间 | 顺光、侧光、逆光、顶光、底光、轮廓光、柔光、硬光；清晨、白天、黄昏、夜晚 | 光线可多选；时间单选 |

“推镜、拉镜、摇镜、跟拍”等运动术语属于时间过程。静态漫画中应转换为“靠近感 / 远离感、透视、主体运动方向、连续格变化”等可见表达，不能直接将电影运镜当作单张图片的能力。

### 3.3 镜头选择器与预设

- 镜头库支持按维度过滤、全文搜索、收藏、最近使用和自定义预设。
- 基础模式优先暴露景别、方向、构图和焦点；高级设置展开其余维度，不能一次铺满所有选项。
- 每项有可识别的示意缩略图，至少体现人物尺度、方向和留白；不使用无关装饰图片。
- 预设是多维字段组合，不是无法编辑的长提示词。应用后仍可改每一个字段。
- 首期至少提供 12 套组合：环境建立、人物登场、正反打对话、过肩交谈、表情反应、手部细节、物件伏笔、主观观察、压迫仰拍、孤独远景、动作冲击、悬念揭示。
- 应用预设默认只替换镜头字段，保留人物、动作、场景、对白；替换描述需单独明确勾选。
- 多选预设批量应用前显示受影响格数，锁定格保持原样并报告跳过数。
- 冲突采用可解释提醒，例如“对称构图”与“偏心构图”；不静默丢弃用户选项。

### 3.4 结构化描述字段

| 字段 | 要描述的内容 | 示例 |
| --- | --- | --- |
| 叙事目的 | 本格为什么存在 | 让读者发现人物隐瞒了某件事 |
| 主体 | 出场人物、外观变化和位置 | A 在左侧，B 只露出肩部 |
| 动作 | 可见动作及动作阶段 | A 停下脚步，右手握紧信封 |
| 表情与情绪 | 面部 / 身体可见信号 | 目光回避，眉头微皱，肩膀绷紧 |
| 场景 | 地点、时间、环境变化 | 黄昏的走廊，窗外雨水，尽头亮灯 |
| 镜头 | 多维结构化字段 | 中近景、过肩、浅景深、手部焦点 |
| 构图与空间 | 主体占比、前中后景、留白 | 人物位于右侧三分线，左上留出对白区 |
| 光影色彩 | 光源、阴影、色温与局部重点 | 窗侧冷光，走廊尽头暖光 |
| 连续性 | 必须与前格一致的细节 | 信封始终在右手，人物面朝走廊尽头 |
| 台词 / 旁白 / 音效 | 独立文字内容与发声者 | B：“你没有说实话。”；音效“滴答” |
| 禁止项 | 本格不希望出现的变化 | 不换衣服、不增加路人、不生成文字 |
| 自由补充 | 结构化字段之外的画面细节 | 雨水倒影中有第二个人影 |

表单支持三种互通编辑方式：结构化编辑、自然语言画面描述、最终提示词预览。自然语言不应被猜测解析后覆盖结构化字段；AI 解析作为显式的建议步骤。最终提示词有“自动组装 / 手动覆盖”模式，覆盖时明确显示其脱离自动组装的状态，并允许恢复。

### 3.5 提示词组装规范

固定组装顺序：项目风格 → 角色身份 / 外观 → 场景 → 动作 / 表情 → 镜头 / 构图 → 光影 → 连续性中的可见约束 → 自由补充。相同输入和同一编译器版本必须产生相同输出。

- 故事梗概与叙事目的默认作为创作上下文，不整段直接塞入图像提示词。
- 中文创作描述原样保存；镜头内置词条可映射英文，自由中文描述不伪装成已翻译。
- 自动去重只作用于词库 ID 对应的片段，不擅自重写用户自由文本。
- 负向提示词由项目默认值 + 分镜补充组成；模型切换时做兼容性检查。
- 对白、旁白和音效独立保存，默认不要求扩散模型绘制中文字；画面可注明留白区域。
- 最终提示词预览显示继承内容、分镜内容和覆盖状态，复制得到实际提交文本。
- 单格生成提交前显示实际模型、尺寸、LoRA 和提示词；选项不支持时提示原因。
- 工作流节点、参数快照和最终提示词保留实际值；不得将逻辑描述当作实际已执行参数。

## 4. 布局与视觉规范

### 4.1 区域与空间分配

使用现有区域命名：`nav` 为全局导航；漫画 `rail` 为页面 / 分镜目录；`stage` 为分镜表或页面画布；`side` 为属性编辑；`modal` 为导入 / 导出等弹窗。此处区域语义仅针对漫画工作台，不改写创建页定义。

```text
宽屏：
┌ 项目名 / 保存状态 ─ 分镜·页面视图 ─ 撤销·重做 ─ 导出 ┐

│ 新增页 / 格    │ 画布缩放 / 适合页面           │ 文字 │

窄屏：

└ 全局导航与安全区          ┘
```

### 4.2 响应式策略

断点以扣除全局导航之后的漫画工作台可用宽度为准，优先 CSS container query；不能只看显示器物理宽度。浏览器缩放、系统 DPR、折叠导航都会改变可用空间。

| 工作台宽度 | 布局 | 设置入口与画布 |
| --- | --- | --- |
| ≥ 1280 CSS px | 三栏 | rail 200–240px、side 300–360px、stage 至少 600px；不足则进入两栏 |
| 900–1279px | 两栏 | rail 收为页选择器 / 可展开目录；stage + 300px side；画布不足 560px 时 side 收起 |
| 600–899px | 单主区 | stage 占满，目录按需打开；设置为右侧面板或独立编辑视图，不持续占据画布 |
| < 600px | 手机形态 | 单列分镜或整页缩略预览；设置为主区子页面，顶栏有明确返回按钮 |

工作台铺满可用主区，不设置固定最大内容宽度。桌面外边距 12–16px，手机 8–12px；工具栏约 48–56px。目录与属性栏可折叠，折叠后 stage 接管空间。宽屏 stage 目标占工作台宽度的 55% 以上，超宽屏避免继续放大属性表单。

工具箱共享外壳新增可选工作台模式，限制在需要全高编辑器的路由；既有视频 / GIF / EXIF 页必须回归验证。全高采用 `100dvh`，扣除已有导航与安全区，不能用多层固定高度互相抵消。

### 4.3 主视图

- “分镜”视图：密集但可扫描的格子列表，展示格号、缩略图、景别 / 用途、描述前两行和状态；展开一格编辑，不嵌入完整表单套卡片。
- “页面”视图：真实页比例及分格边界；点选格后编辑属性；未生成格显示简短描述与格号，可辨识阅读顺序。
- 图像使用 contain 查看全图；应用到格时独立设置 cover 裁切和焦点，不因选中候选图而静默裁掉主体。
- 普通列表禁止横向溢出；画布允许在显式缩放模式中平移，并提供“适合页面”恢复入口。
- 大项目虚拟化分镜列表并按需加载缩略图；减少同时解码的原图数量。
- 自定义排版仅拖动操作时显示对齐线 / 网格，日常阅读画面保持干净。

### 4.4 低宽度下的统一设置

所有宽度复用同一套设置字段、校验与保存逻辑，改变容器，不另做一套手机表单。统一入口为“设置”，内部顶部范围菜单为“项目 / 当前页面 / 当前分镜”，下方固定为“画面 / 镜头 / 排版 / 文字 / 生成”五个标签；窄屏标签条可横向滚动。不适用字段隐藏或明确禁用，不让页面边距误作用于单格。

- 项目设置显示默认值；当前分镜设置显示“继承 / 自定义”，禁止同名字段含义不同。
- 项目没有当前分镜时，分镜范围不可选；批量选中时范围切为“选中 N 格”。
- 宽屏在 side 中即时编辑；手机进入主区子页面，顶部保留格号与上一格 / 下一格切换。
- 参数编辑即时写入工作草稿，返回不会丢失。复杂批量操作和预设替换采用显式“应用”。
- 返回工作台恢复页码、滚动位置、画布缩放和当前格，不能重新打开项目第一页。
- 软键盘弹出时 textarea 与提交操作可见；设置编辑页不同时叠加工具条、底部 tab、全局导航占满屏幕。
- 非模态编辑保持全局导航；手机模态文件选择 / 预设选择隐藏背景交互，关闭后恢复焦点。
- 屏宽 320px 不出现被截断的按钮、超出屏幕的弹窗或右侧不可触及的操作。
- 手机浏览器可编辑、导入浏览器文件、保存本地草稿与下载 JSON；Electron 专用功能按实际能力禁用并展示简短原因。
- 手机远程调用桌面 ComfyUI 需要单独的鉴权服务与网络方案，首期不隐含开放本机端口。

### 4.5 美观与可读性

沿用应用浅色 / 深色语义色，页面背景、画布背景与编辑表面形成明确层次。中性色承担布局，主色用于主操作，选中描边和状态色各有明确职责；避免全页单色渐变或装饰性大卡片。

- 正文 14px 左右，辅助信息 12–13px，紧凑标题 16–18px，项目标题不做 hero 级排版。
- 信息层级为项目 → 页面 → 格号 → 镜头摘要 → 描述，不让每一行都同样粗重。
- 工具按钮使用现有 lucide 图标和 tooltip；单纯命令才用文字按钮。
- 触控命中区域至少 44×44px；桌面图标按钮可为 32–36px，但不能依赖 hover 才能操作。
- 卡片和面板圆角原则上不超过 8px；页段落使用平面分区，不在卡片中再嵌卡片。
- 长项目名和镜头名允许省略并查看全文，正文描述允许换行；固定按钮尺寸避免内容改变导致布局跳动。
- 正文对比度至少 4.5:1，交互状态不能只靠颜色，选中需同时有描边 / 标记 / 格号反馈。
- 普通缩放与过渡不遮挡画面，遵守减少动态效果偏好；没有操作时不播放无意义动画。

## 5. 页面排版、角色与连续性

### 5.1 排版

首期提供单格、左右双格、上下双格、三格、四格网格、上大下双、上双下大、顶部大场景 + 右侧跨行竖格 + 左侧反应格、跨列横格混排、纵向长条及异形跨格模板。模板应用必须可撤销；内容映射规则见 5.6，不能丢弃已有格。

- 阅读方向支持左到右、右到左、纵向；默认左到右。
- 页尺寸由像素宽高决定，印刷 DPI 只是导出换算参数，不混入 CSS 像素。
- 格间距、页边距、描边宽度统一用页面坐标，改变预览缩放不改变导出结果。
- 分镜内容顺序与几何位置分开保存；改变阅读方向先预览新的编号，再明确应用排序。
- 普通排版尊重所选模板，常规页漫默认保留矩形，异形模板突出不规则多边形；不规则轮廓本身不表示重叠。首期同时提供显式的“跨格叠放”模式，支持斜切、多边形和撕裂边缘。普通移动不自动变为叠放，跨格组合的规则见 5.4。
- 首期所有分镜轮廓保持在页内，允许跨越格间距与其它格；跨出页面裁切边界的印刷出血另行排期。
- 长条首期以顺序排格为主，不能暗示已经支持无限大单张图片；大图导出有尺寸上限和分段策略。

### 5.2 角色与场景

角色身份库保存名称、固定外观、服装状态、参考图与提示片段；分镜角色实例保存姿态、表情、位置和面朝方向。场景库保存地点、时间、参考图和环境提示，分镜允许局部变化。

角色和场景采用引用，不把同一段基础描述复制到每一格。删除被引用项需提示影响并提供替换 / 保留快照。换页和改镜头不能清空角色；模型和 LoRA 切换提示不兼容项，不静默清除创作描述。

连续性备注可记录屏幕方向、道具持有者、服装、时间和光源。首期允许人工记录；后续 AI 检查只提出建议。角色参考图、固定种子和提示词有助于一致性，但不能承诺一致性保证。

### 5.3 叙事如何拆成多个分镜

故事内容先拆为“叙事节拍”，再选择视觉呈现方式。一段动作、一个发现或一次情绪变化可以对应多个格；一个跨格构图可以连接多个节拍。不能把“一个句子 = 一个格”作为固定规则。

用户选中一段故事或已有格，使用“拆成分镜”，指定格数和拆分方式。首期以可编辑模板辅助人工拆分，预览各格叙事目的、镜头与描述后再创建；AI 自动填写在 P2 接入同一套结构。拆分已有格默认保留原格，替换需要明确选择且可撤销。

| 拆分方式 | 视觉组织 | 适用情境 |
| --- | --- | --- |
| 动作分解 | 起势 → 动作中 → 接触 / 冲击 → 余势 | 打斗、跳跃、开门、递交道具 |
| 情绪递进 | 外部刺激 → 面部反应 → 手 / 身体细节 → 决定 | 犹豫、震惊、压抑、下定决心 |
| 信息揭示 | 环境 → 局部线索 → 角色视线 → 真相 | 伏笔、悬念、身份揭露 |
| 对话交锋 | 说话者 → 听者反应 → 正反打 → 关系变化 | 争执、谈判、告白 |
| 同时发生 | A 的行动与 B 的行动交叉排列，标明同一时刻 | 追逐、异地呼应、双方准备 |
| 时间拉伸 | 同一瞬间拆成视线、手、物件、冲击等细节 | 关键一击、惊险擦身、重要决定 |
| 时间压缩 | 若干时间节点形成蒙太奇，明确跳时 | 训练、旅行、等待、成长 |
| 空间分解 | 全景建立 → 人物位置 → 局部动作 | 复杂场景、战斗位置、环境探索 |

每组保存原始故事片段、节拍 ID、各格叙事任务及时间关系（连续 / 同时 / 跳时）。页面中的阅读顺序仍可人工调整，调整时提示可能的时间关系变化，不静默改写故事。

例：“挥刀造成破裂”可拆为 A 格起势、B 格对手反应、C 格冲击后的环境，再增加 D 格斜向撕裂的刀光作为视觉高潮。D 可以跨过 A/B/C 的部分区域；是否表示同一瞬间由用户指定，而不是由叠放位置自动推断。

### 5.4 跨格叠放、破格与斜切覆盖

这里的“斜切覆盖”是页面排版形状，“斜视 / 倾斜机位”是画面镜头，两者独立。目标组合为：三张底层分镜保持自己的完整图像，上方新增一张斜切或撕裂形分镜，只在轮廓内遮挡三张底图的部分区域，其余区域仍可阅读。

| 表现方式 | 实际行为 | 范围 |
| --- | --- | --- |
| 跨格叠放 | 完整独立分镜位于其它格上方，可跨多个格及格间距 | P0 |
| 斜切覆盖 | 通过斜向多边形轮廓裁切上层图像，轮廓外显示底层画面 | P0 |
| 撕裂覆盖 | 上层格使用可调方向、宽度与不规则度的撕裂轮廓，形成裂口 / 冲击感 | P0 |
| 插入小格 | 局部特写叠在大格内，突出眼睛、手、道具等细节 | P0 |
| 主体破格 | 人物或道具抠图越出原分镜边界，透明背景保留底图 | P2；需要 alpha 图像 / 蒙版及独立主体层 |
| 跨页大场面 | 同一画面占双页，并处理书脊安全区 | 后续；不等同于同页跨格 |

“撕裂”通过真实多边形 / 蒙版裁切和边缘描边实现，不能只贴一张撕裂装饰图片，也不能只降低整个矩形的透明度来模拟不完全覆盖。上层图片原图保持完整，轮廓、裁切与叠放仅属于排版数据。

撕裂视觉以手撕相片为参考：边缘步长不等、起伏不对称，混合较大的缺口与细碎纸边，避免等距锯齿或规则波浪；白色纸芯边与轻微投影可独立开关和调节。画面内容、轮廓、纸边材质分开存储，不能将“撕纸”提示词当作实际排版。预设至少包括斜向不规则四边形、不规则五 / 六边形和相片撕裂；桌面支持增删 / 移动顶点，手机通过统一设置选择预设及调节形状参数，保留矩形回退。

边缘风格对全部分镜开放，而非覆盖格专属：普通底格也可独立选择手撕相片、毛边回忆或冲击碎裂，混排时保留各格独立种子。随机缺口需包含非周期的大缺口、长短不一的撕痕与细碎边缘，不能只在直边上增加等幅锯齿。“换裂口”只改变当前格；批量应用为显式命令，可整体撤销。单边撕裂和手工指定缺口位置作为后续精调能力，不冒充当前原型已支持。参考与原型预设依据见 `docs/prototypes/comic-storyboard/style-references.md`。

不规则轮廓的取景必须可独立平移 / 缩放，不能仅用居中铺满而截掉人物或对白。可见面积按实际多边形计算，不以其外接矩形代替。编辑与导出使用同一组实际顶点；修改视角不自动改变轮廓，修改轮廓不自动重写画面描述。

#### 创建与编辑流程

1. 选中同一页的一格或多格，执行“添加跨格分镜”。
2. 选择斜切、撕裂或插入小格预设；新增独立分镜 D，与选中的底格建立组合引用；A/B/C 为三格示例。
3. 预览 D 的方向、位置、宽度和轮廓；底层 A/B/C 不被合并或替换。
4. 在“排版”设置中调整形状、上移 / 下移图层、裁切焦点、描边与可选透明度。
5. 指定 D 的阅读位置和时间关系，确认后保存整组；新增、改形状和解除组合均可撤销。三格是示例，实际可选一格或多格作为底层。

- 统一设置中的“排版”标签承载轮廓、层级、裁切和遮挡规则；不能让所有标签缩成难以点按的按钮。
- 桌面支持拖动多边形顶点；手机默认提供方向、位置、宽度滑块和轮廓预设，顶点精调为可选模式，不要求用户精准拖拽微小节点才能使用。
- 点击默认命中最上方可见图层；通过图层列表、“选择下层”菜单和临时隐藏上层访问被遮挡格。轮廓外透明区域的点击应穿透至实际可见底层。
- 页面阅读顺序与绘制叠放顺序分开设置；“置顶”不改变叙事编号，“先读”不改变遮挡。
- 初始预设目标为每张底格至少保留 50% 的可见面积。默认每张底格至少保留 30%，且不能完全遮住其对白或用户标记的关键区域；超出时显示逐格提示，用户可明确确认破格效果，不静默挪动已编辑内容。
- 可见面积按裁切轮廓及叠放遮挡计算；透明度不算作恢复面积，避免以低透明度满足规则但画面仍难读。
- 关键区域是用户指定的归一化矩形，不假定首期存在自动人物 / 对白识别；未标记时只检查总面积，说明关键内容尚未检查。
- 不在本组目标中的格若也被覆盖，预览时列出并要求加入组合或调整形状，避免误伤其它叙事。
- 删除底格时移除组合引用并提示；删除上层格时底格原样恢复。解除组合默认保留上层独立分镜，删除须另行执行。
- 同页移动整组保持相对位置；跨页移动要求整组移动或先解除组合，禁止悬空引用。锁定格及涉及它的遮挡变化需先解锁。
- 导出与编辑预览使用同一轮廓、裁切和图层顺序；不把跨格布局交给扩散模型自行绘制。

#### 叙事与布局模板

首期新增“斜向冲击跨三格”“撕裂揭示跨三格”“大格中的反应特写”“上下场景间的桥接格”四种模板。模板同时给出可编辑的叙事任务与排版，不强行绑定人物和故事内容。

跨三格示例：A 为动作起势、B 为惊讶反应、C 为环境结果、D 为斜向冲击。阅读顺序可设 A → B → D → C；绘制顺序仍是 A/B/C 在底、D 在顶。两种顺序需在界面和文件中分别可见。

### 5.5 切格、合并与共享边界

页面明确区分“联动分格”和“自由排版”：前者用于规则或斜切的不重叠页漫，后者用于独立异形格、插入格和跨格叠放。边缘撕裂是格的表现，不自动解除联动；自由拖动某格需要先明确解除对应约束，不能偷偷破坏邻格。

- 从页边距内的一个大格开始，可水平、垂直或斜向划线切分。桌面使用切格工具拖线；手机在统一“排版”设置选择方向、位置百分比和斜度，预览后应用；取消无修改。
- P0 联动格的基础单元为凸多边形；切线延伸到所选单元边界，必须形成两个连通、非退化区域。与边界重合、只擦过角点、产生空格或低于最小尺寸时拒绝。自由凹多边形允许顶点编辑，但自动切分留到后续，不能默默凸化。
- 每次切分先显示两格尺寸和内容策略：默认用户指定的一侧保留原 ID / 描述 / 图像 / 文字，另一侧新建空白格；可选复制创作内容或“同图连续切片”。复制候选必须创建属于新格的新候选记录，不能直接引用其它格的候选 ID。操作整体可撤销。
- 新格默认紧邻原格插入阅读顺序；明确预览保留格和新增格的位置，图层顺序另行更新。切分不是自动拆故事，选择“拆成分镜”才使用叙事模板。
- 共享分界线可拖动或用位置 / 角度输入调整；所有相关邻格一起变化，页边距和指定格间距保持，内部分割端点随父区域变换。涉及锁定格则拒绝整个操作，不只移动一侧。
- 默认最小基础格包围盒宽高各 64 页面像素、面积至少 4096 平方页面像素；约束依据页面尺寸，不随屏幕缩放改变。特殊细长格可明确降低页面限制，但正面积、不自交和页内约束不可解除。
- 共享分界线与基础格间距是页面结构参数；撕裂、纸边和投影会改变视觉留白，应另做碰撞提示，不能把视觉边缘当成可随意拖动的共享切线。
- 支持长竖格旁分成上下小格、横向大格跨列，不要求每一行都拥有相同列数。普通模式默认不重叠；自由模式可叠放，但列出受影响格并检查遮挡。
- 合并联动树中的相邻兄弟叶格可恢复父区域；预览中明确选择保留哪一个格 ID 和内容。其它格的描述、文字与候选默认归档到该格的合并来源记录，或由用户移到其它页，不静默删除或拼成一张新图。
- 非兄弟格只提供显式“解除联动并合并”；仅当几何并集为无洞的单个简单多边形时允许。受影响的联动子树须预览解除范围；有洞、分离区域或锁定成员则拒绝。
- 页面边距、基础格间距、基础描边可统一修改；有局部覆盖时显示继承 / 自定义。调整页尺寸先选择按比例缩放或保持页面像素样式，预览后作为一次事务应用。

### 5.6 版式模板与内容映射

- 内置和用户模板分为页面规格预设、纯分格模板和叙事镜头预设；不把这三种内容混为一个“风格”。模板缩略图真实显示跨行跨列、格号和异形结构。
- 保存版式模板只保存尺寸比例、联动结构、格形、边缘参数、阅读顺序、插入 / 覆盖关系与占位 ID，不包含角色、对白、图像、候选、路径或密钥。默认固定裂口；重新随机化是显式选项。
- 新页套用模板生成全新页面 / 格 / 关系 ID；模板占位 ID 通过映射替换，不能与原页产生交叉引用。
- 有内容页换模板先展示“旧格 → 新位置”的映射，默认按现有阅读顺序一一匹配，允许手动调换。被保留的格 ID、描述、资产与候选不变；文字与图像位置有越界风险时提示，并可重新取景，不默默缩放字体。
- 新槽位更多则新增空白格；槽位不足则要求选择追加页、保留为自由格或取消。应用前必须处理全部旧格，包括无槽位的叠放格。涉及锁定格、联动或跨格关系时预览影响，无法保持约束则拒绝。
- 覆盖关系按映射重连；成员缺失时须先解除或重新指定，不保留悬空 ID。整个换模板操作是一个撤销事务。
- 用户模板支持命名、预览、复制、删除、JSON 导入导出；模板独立格式为 `illusion-realm-comic-layout-template`、version 1，使用项目相同的几何与限制校验，不将任意项目 JSON 当模板。

### 5.7 阅读路径、时间与连续性

阅读顺序、故事时间、图层顺序为三个独立概念。格大、位置靠右或位于上层，都不代表先读或更早发生。

- 提供“阅读路径”视图，显示页内编号与箭头，可通过目录排序或前后移动调整；路径仅是编辑辅助，不写入成品 PNG。预览按钮逐格聚焦，手机仍可前一格 / 下一格。
- 按左读 / 右读 / 纵向生成的几何顺序仅作为建议，有跨行竖格或交错格时显示待确认；用户确认后才改 panelOrder。文字在页内有独立顺序，不由文字框 x/y 猜测。
- 首期支持节拍序列、同时组、回忆、预兆和蒙太奇。每格可引用多个节拍；同一节拍可被多格呈现；时间组明确保存成员和共同时间标识，不仅写“同时”而无法知道与谁同时。
- 回忆 / 预兆组可引用所在叙事组作为上下文，允许有限嵌套，默认上限 4 层；必须无环。阅读顺序仍由页面决定，组内 chronologyOrder 表示故事时间，不用于改页内编号。
- 调整顺序、删格或跨页移动时检查节拍、时间组和连续性引用；同页布局关系不能跨页，叙事关系允许跨页。引用断裂需修复或明确解除，不默默改变时间含义。
- 对话可指定对话轴、人物左右位置、面朝方向、视线目标；动作用 screenDirection 与动作阶段记录；道具记录持有者和外观。越轴、左右反转、道具易手仅人工检查 / 明确确认，首期不假装自动识图。
- 时间切换可用环境、日夜、道具细节、旁白或格框表达，但换格框不自动改时间字段；阅读路径也不能证明叙事正确。

### 5.8 同图连续切片与独立取景

- 独立取景支持平移、缩放、旋转及 contain / cover，默认保留候选原图。格形改变时保持当前取景，超出图像覆盖范围或遮住已标记主体时提示；“重新适合格子”才重置。
- 同图连续切片组的各格共享一个源资产和同一页面坐标图像变换，再各自裁切；移动共享取景会一起更新，格间缝隙仍显示页面底色。禁止以逐格 cover 造成接缝处重复或错位。
- 连续切片支持联动矩形格和自由多边形格；有候选格加入时须确认替换当前取景，旧候选保留。脱离组时将当前页面变换换算为格内独立变换，画面不跳动。
- 连续切片默认表示同一空间，是否同一瞬间由叙事字段决定；文字、边框、阅读顺序仍逐格独立。

### 5.9 基本文字、气泡与层级（P0）

- P0 支持对白、旁白、音效三种文字项；横排和 `vertical-rl` 竖排、中文标点方向、字体 / 字号 / 行距 / 内边距 / 对齐可编辑。缺字体时警告并使用明确回退，导出采用与预览相同的实际字体。
- 基本外形为无框文字、矩形旁白、椭圆对白与矩形对白；气泡尾巴起点和目标可编辑，并可关联发声角色实例。复杂气泡素材、字形弯曲和轮廓音效排到 P2。
- 文字可属于分镜或页面：标题、跨格旁白可使用页面坐标；格内对白用分镜坐标。跨格文字不通过复制到多个格实现；发声角色和视线目标分开保存。
- P0 渲染固定为页面底色 → 分镜图像 / 格框按 renderOrder → 全部文字按 textRenderOrder；文字层在图像上方，可关闭单项。文字阅读顺序 textOrder 与绘制顺序分开；任意文字夹在图像层之间属后续能力。
- 溢出提供扩框、调字号或保留警告的显式操作，不静默截字或自动缩小到不可读。对白压住保护区、尾巴指错对象和文字跨页边界需提示；未提供检测依据不报假安全。
- P0 PNG 包含启用的文字与基本气泡，不要求图像模型生成中文字。文字尚未排版或存在缺失字体 / 溢出时，导出前明确选择修复、忽略该项或确认当前外观。

## 6. 数据格式与保存规范

### 6.1 项目文件

项目文件推荐后缀 `.ir-comic.json`，MIME `application/json`，UTF-8。顶层必须有 `format: "illusion-realm-comic"` 与整数 `version: 1`。所有新增不兼容格式必须递增版本并提供迁移；不能按文件名猜格式。

| 对象 | 核心字段 | 约束 |
| --- | --- | --- |
| Project | id、title、synopsis、createdAt、updatedAt、revision、defaults、characters、scenes、storyBeats、narrativeGroups、continuityLinks、pages、panels、assets、candidates | 项目 ID 稳定；revision 随持久化内容修改递增 |
| Page | id、name、canvas、layout、panelStyleOverride、readingDirection、panelOrder、renderOrder、textOrder、textRenderOrder、textItems、panelCompositions、imageGroups | panelOrder 为唯一格阅读顺序；renderOrder 为唯一格绘制顺序；layout 保存联动约束，不另存一份格顺序 |
| Panel | id、pageId、locked、frame、baseShape、shape、edge、edgeOverride、border、paperEdge、shadow、imagePlacement、imageGroupId、opacity、protectedRegions、narrative、characterInstances、sceneId、description、shot、textItems、mergedSources、promptMode、generationOverride、candidateIds、selectedCandidateId | 引用存在；一格属于一页，frame 是轮廓局部坐标参考框，不要求是紧包围盒 |
| StoryBeat | id、sourceText、summary、decompositionMethod、temporalRelation | 分镜 narrative.beatIds 引用零个或多个节拍；同一节拍可对应多格 |
| NarrativeGroup | id、kind、beatIds、chronologyOrder、parentGroupId、timeLabel | simultaneous / sequence / flashback / premonition / montage；父链无环，时间不等于阅读顺序 |
| ContinuityLink | id、fromPanelId、toPanelId、kind、subjectInstanceIds、notes、confirmed | 视线 / 动作方向 / 对话轴 / 道具 / 场景关系；无自动识图保证 |
| PanelComposition | id、kind、basePanelIds、overlayPanelId | 同页跨格组合引用，保存叙事目的和遮挡规则；不另存与 renderOrder 冲突的 zIndex |
| Character / Scene | id、name、description、referenceAssetIds | 引用独立资产，允许中文创作内容 |
| Asset | id、kind、locator、width、height、contentHash | 原图 / 参考图 / 候选图通过 ID 引用，避免重复塞入项目 |
| Candidate | id、panelId、assetId、source、createdAt、generationSnapshot、provenance | source 为 imported / generated / reused；候选归属唯一，生成快照不可变 |
| ShotPreset | id、catalogVersion、name、shot | 用户命名与内置词条 i18n 分离 |
| LayoutTemplate | format、version、id、name、canvasRatio、layout、slots、panelOrder、renderOrder、compositions | slots 使用模板占位 ID；不带项目内容或资产 |

### 6.2 字段约定

- 属性名 camelCase；内置枚举与词库 ID 使用稳定 kebab-case 英文；展示中文走 i18n。
- ID 推荐 UUID；跨对象引用与数组排序分开；不从名称、文件路径或索引生成 ID。
- 时间为 UTC ISO 8601 字符串，界面按当前时区显示。
- 缺省的可选字段表示继承；显式 `null` 只用于允许的“清空 / 未选择”字段，不能同时表达不同含义。
- 数字必须有限；尺寸为正整数，种子 / steps / CFG / LoRA 范围复用当前生成契约。
- `frame` 与文字留白 `box` 为页面 / 分镜内归一化坐标：x、y、width、height 均为 0–1，且 x+width、y+height 不超过 1。
- 分镜 frame 相对于页面；页级文字 box 相对于页面，格级文字 box 相对于分镜 frame；坐标上下文由所属对象明确决定，不能混用。
- `shape` 顶点相对于分镜 frame，顶点均在 0–1；frame 保持轴对齐，斜切通过多边形表示。阅读排序不能被渲染排序复用。
- 角度统一为度；颜色为 `#RRGGBB` / `#RRGGBBAA`；透明度为 0–1。
- UI 状态如选中项、滚动、缩放、侧栏折叠、未完成网络任务不进入可交换项目正文。
- 不保存 API Key、token、服务密钥、浏览器 blob URL 或瞬时 IPC ID。
- 内置镜头 ID 与词库版本一起保存；手写镜头描述独立保存。未知词条保留原值并显示待修复状态，不直接丢弃。

### 6.4 资产与便携性

首期 JSON 保存描述及资产引用，不假装图片已随 JSON 打包。Electron 工作项目目录建议：`project.ir-comic.json` + `assets/` + `exports/`；项目资产使用相对于项目目录的路径，由主进程解析。

- 导入外部图片时优先复制到项目 assets；引用外部文件需明确标识“外部链接”，搬家后允许重新定位。
- 路径验证禁止越出项目根，拒绝 `..`、非允许协议和可执行内容；不使用简单字符串前缀代替路径边界验证。
- 不将图片 base64 写入常规项目 JSON。后续可增加包含 manifest 和 assets 的便携 ZIP 包，导入需要限制解压路径、数量和总尺寸。
- 手机浏览器的图片资产保存在 IndexedDB；JSON 单独下载不能携带这些资产，导出前列出需另行导出的图片。尚未实现便携包前不能显示“完整备份”字样。
- 资产缺失时保留分镜和元数据，显示缺失状态并允许重新关联，不能把整份项目当作空项目。

### 6.5 保存、导入和迁移

桌面保存和读取走最小 IPC API，项目文档保存在独立项目文件；现有用户 JSON 仅保存最近项目和 UI 偏好，不嵌入整篇漫画。浏览器首期使用 IndexedDB 工作草稿和显式 JSON 下载，不依赖 localStorage 容量承载图片项目。

- 文本输入建议 800ms 防抖保存；排序、应用候选、批量编辑等事务结束后保存；界面有“保存中 / 已保存 / 保存失败”。
- 主进程原子写入：同目录临时文件写完后替换，并保留最近一次可恢复备份；保存失败不报“已保存”。
- 保存请求带 revision，旧 revision 完成不得覆盖新状态；有外部文件修改时提示冲突，不静默覆盖。
- 运行中的任务放在独立任务记录；重开项目先向后端核对，再标为继续、已完成或已中断，不能永远“生成中”。
- 导入先解析 / 校验 / 预览摘要，成功后作为新项目打开，不在校验完成前清空当前项目。
- schema 校验结构、范围、枚举、重复 ID、悬空引用、格页归属与顺序完整性；错误说明定位到页 / 格 / 字段。
- 建议上限：JSON 10MiB、100 页、1000 格、单字段 20000 字符；超限明确拒绝，不部分导入。性能基线另见验收。
- 未来版本不能被旧客户端默认按 v1 打开或覆盖；旧版迁移先写新文件，保留原文件。
- 不识别无版本的任意 JSON 为漫画项目；旧对话框草稿要通过显式转换入口导入。

### 6.6 子对象与覆盖约束

| 子对象 | 规范 |
| --- | --- |
| defaults.generation | `null` 表示尚未配置；配置时保存 series、模型引用、LoRA 引用、尺寸、steps、CFG、采样器、调度器与种子策略；任务提交时解析成实际值 |
| generationOverride | 仅保存显式覆盖字段；空对象表示全部继承。LoRA 列表覆盖采用整列表替换，空数组明确清空，不隐式合并重复模型 |
| shot | 每个维度使用独立字段；相应项目默认字段放 defaults.shot，分镜中省略字段表示继承，空数组表示明确不使用该效果 |
| promptMode | `assembled` 或 `manual`；manual 时必须有非空 promptOverride，切回 assembled 保留旧手写内容供恢复，但提交只用编译结果 |
| textItems | id、kind（dialogue / narration / sound-effect）、speakerInstanceId、text、box、style、bubble、enabled；页或格归属决定 box 坐标；未排版 box 为 null。P0 排版后可渲染，顺序见 6.12 |
| characterInstances | instanceId、characterId、pose、expression、screenPosition、facing、appearanceOverride；同一角色可有多个实例，各自有独立 instanceId |
| asset.locator | 判别联合：project-relative + path、external-file + path、browser-storage + storageKey；浏览器存储引用跨设备可能失效，导入不得假装可解析 |
| asset.kind | reference-image / imported-image / generated-image；width、height 必须与解码后尺寸一致，contentHash 推荐 SHA-256 |
| selectedCandidateId | 必须属于当前格 candidateIds，且关联候选的 panelId 与当前格一致；未选择为 null |

手工导入图片也创建候选记录，source 为 imported、generationSnapshot 为 null；generated 必填生成快照；复制 / 切分复用图片时新建 source 为 reused 的候选，保留 provenance 原来源摘要，不冒充重新生成。旧生成快照不改 panelId，复用记录的 generationSnapshot 为 null。资产引用和任务输出不能用同一字段混存。

### 6.7 跨格组合数据契约

- `Page.panelOrder` 和 `Page.renderOrder` 都必须恰好包含本页所有 panelId 一次；前者为阅读顺序，后者为从底到顶绘制顺序。
- `Panel.shape` 为 rectangle 或 polygon 判别联合；polygon 至少 3 个顶点，轮廓闭合，不自交、不退化、不重复末尾首点。撕裂轮廓也保存实际顶点。
- 撕裂预设可另存 presetId、参数与生成器版本用于后续编辑，但实际顶点为渲染事实源；导入或打开文件不能随机重新生成边缘。
- `Panel.imagePlacement` 保存图像在 frame 中的缩放与位移，`opacity` 控制整体透明度；默认 1。shape 只裁切自己的图像 / 底色 / 边框，不裁切底层格。
- `protectedRegions` 为带 id、kind（subject / text / custom）、box 的数组，box 相对于分镜 frame。对白 box 已确定时也纳入检查。
- 组合 basePanelIds 非空且唯一；overlayPanelId 不得出现在 basePanelIds，所有成员须同页存在，上层格在 renderOrder 中高于全部底格。
- 同一底格可以被多个覆盖格引用，覆盖格也可作为下一层底格；每个覆盖格最多拥有一条组合定义。所有 base → overlay 边须构成有向无环图，并符合 renderOrder，禁止自引用和间接循环。不另建含糊的嵌套组变换。
- 编辑整组时显式选择当前组合或关联闭包，显示实际涉及的去重格数；同一格只移动一次。删除、解除和跨页移动须处理全部受影响关系，锁定成员使事务整体拒绝。关联闭包默认上限 64 格，超限要求缩小操作范围。
- 组合保存 narrativePurpose、temporalRelation 与 visibilityPolicy；面积结果是派生值，不保存会过期的 visiblePercent。用户确认遮挡警告记录在编辑事务中，后续几何变化需重新检查。

### 6.8 生成快照与 PNG Meta

生成快照必须记录：源项目 revision、panelId、模型系列、可移植模型名、LoRA 名与权重、实际种子、steps、CFG、采样器、调度器、尺寸、最终正负提示词、提示词编译器版本、提交时间、实际工作流与结果资产。

项目编辑导致生成配置变化时，正在运行的任务使用提交时快照；结果显示“来自较早版本”，不能标为当前配置的新图。回调按 projectId + panelId + jobId 关联，不按“当前选中格”填图。

图片保留现有 `prompt` 和独立 `illusionRealmMeta` 约定，`prompt` 与提交 API Prompt 完全一致。漫画溯源若使用独立 `illusionRealmComic` tEXt 块，必须带自身 version，并明确只保存项目 / 页面 / 格 ID、快照关联和必要摘要；不能塞整份项目。增加块前先建立当前格式与无漫画块旧图的配对兼容测试，不擅自修改既有 Meta 版本语义。

### 6.9 联动分格与编辑事实源

- Page.layout.mode 为 partitioned / free / mixed；partitionTree 为 null 或版本化切分树。free 的树必须为 null；partitioned 全部分镜都在树中；mixed 同时有树成员和自由格。自由格、插入格不进入切分树。
- 切分树根区域是页面 marginPx 内的矩形；节点为 `{kind:"leaf", id, panelId}` 或 `{kind:"split", id, cut:{start,end}, gutterPx, children:[node,node]}`，start/end 使用页面归一化坐标，children 固定两项。节点 ID 唯一，无环；一个联动格只出现于一个叶节点，同页引用，不要求覆盖全部自由格。
- cut 是父区域两个边界交点，gutterPx 为沿切线法向的完整空隙宽度；两侧各留一半。连续切分后先校验最小格与所有邻格，不通过就回滚。联动子树内切线端点映射跟随父区域变化，不能遗漏子格。
- 树是联动编辑约束，Panel.frame / baseShape / shape 是落盘渲染事实；一次编辑同时提交二者。导入按固定 solverVersion 校验树推导的基础区域与落盘 frame / baseShape 一致，不自行重新排版或用树覆盖用户轮廓。
- 不支持的 solverVersion 拒绝作为可编辑项目导入，保留当前草稿及原文件；不能套用最新求解器使格线改变。独立原型文件的格式与版本不等于正式项目 v1，不自动按正式项目读取。
- 简单联动格可仅切分对应叶节点；自由顶点编辑若改变基础区域，先明确解除受影响联动子树，保留全部成员当前几何。程序不得在两份不一致几何间任选一份渲染。
- 最小格限制检查基础区域；最终撕裂轮廓还需检查正面积与自交。页面边距、间距、最小格和 solverVersion 随文件保存；页边距不得使根区域为空。
- mergedSources 保存被合并格的内容、文字和候选内联快照与资产引用，不计入当前 panelOrder / renderOrder；归档内容不是活跃分镜。内部引用使用快照本地 ID，不与活跃项目 ID 混用；归档候选不留在 Project.candidates 中，资产仍保留。仍被外部时间组 / 连续性 / 组合引用的旧格必须先重连或保留到其它页，不能仅塞进归档导致悬空。可通过“恢复为分镜”创建新 ID 并重映射内部引用，不直接复活旧 ID。

### 6.10 轮廓、边缘与材质

- baseShape 为用户编辑的基础 rectangle / polygon；shape 为实际裁切轮廓。straight 时二者等价；procedural 时 shape 必须是含实际顶点的 polygon。帧变化后重新规范局部坐标，保持世界取景；不能只改包围框而拉伸内容。
- edge 为 `{kind:"straight"}` 或 `{kind:"procedural", presetId, seed, generatorVersion, roughnessPx, parameters}`。P0 presetId 为 photo / memory / impact；seed 为 0–4294967295 整数，roughnessPx 为 0–128 页面像素。parameters 首版可选字段为 spacingPx（2–128）、largeNotchRate（0–1）、largeNotchDepthPx（0–128）；省略使用该版本预设默认，不接收脚本或未定义字段。
- 刷新、缩放、导入不能随机生成新 shape。换裂口才改 seed 并提交新实际顶点；预设未知时保留 shape 和原参数、禁用参数编辑并提示，不丢画面；未知主格式版本仍拒绝打开覆盖。
- border 为 enabled / widthPx / color，paperEdge 为 enabled / widthPx / color，shadow 为 enabled / blurPx / offsetXPx / offsetYPx / color；各项独立，不用 opacity 同时控制图像与纸边。
- 样式字段位于 defaults.panelStyle、Page.panelStyleOverride 和 Panel 的 border / paperEdge / shadow，按项目 → 页面 → 分镜逐字段解析；省略字段继承。边缘参数覆盖另存 Panel.edgeOverride，edge 为已解析快照；项目 / 页默认 edge 不含 seed。默认几何参数改变时，对未覆盖格保留各自 seed 并重新生成 shape，作为可撤销事务；未知生成器或锁定成员先报告冲突，不部分应用。矩形仍可有裂口，无框只关闭 border。
- 顶点数量 3–2048，页面归一化几何误差容限 1e-6；自交、重复相邻点、零面积拒绝。手工增加顶点不得越过上限；简化须预览后确认，不静默改变裂口。
- 轮廓顶点须在 frame 内，frame 在页内；纸边和投影可以超出 frame，但成品统一裁切到页面。边缘扩张触及邻格 / 安全区有提示。可见面积只计算图像轮廓，并独立检查纸边 / 投影与保护区碰撞，不能宣称百分比覆盖了所有遮挡。
- 曲线和复合蒙版为后续 shape 判别类型，正式发布后需版本化；P0 不把任意曲线粗略转多边形却声称无损兼容。

### 6.11 图像变换与同图组

- Panel.imagePlacement 在无图时为 null，有图时为 `{fit, scale, offsetX, offsetY, rotationDeg}`；fit 为 contain / cover / custom。scale 是源图像像素到页面像素的正比例，offsetX/Y 是源图像中心相对 frame 左上角的位置，以 frame 宽高归一化，允许 -8–8；rotationDeg 为 -180–180 度，绕图像中心旋转。
- contain / cover 应用时先计算实际变换并保存；后续编辑设为 custom。图像像素先缩放 / 旋转，再定位到中心，再由最终 shape 裁切；预览缩放不得参与该变换。
- ImageGroup 为 `{id, assetId, panelIds, placement}`，placement 使用相同 scale / rotationDeg，但 offsetX/Y 相对于整页；成员同页、非空且唯一。每格最多属于一个 imageGroup；Panel.imageGroupId 与组成员双向一致。
- 组成员仍保留候选历史，但显示图像以组 assetId / placement 为准；替换候选或切换图像先要求脱组或明确替换整组。独立 imagePlacement 在组内不参与渲染，脱组时换算当前变换。
- 页尺寸变更时按选择的策略更新 scale 和样式；不同时把坐标与像素比例乘两次。复制页时 imageGroup 和成员 ID 全部重映射，资产可以共享。

### 6.12 文字与叙事关系契约

- Page.textOrder / textRenderOrder 分别恰好包含本页全部页级及格级文字 ID 一次，包含暂未排版和关闭项；两者独立。文字 ID 全项目唯一，格移动 / 删除时更新所属页两份顺序。
- textItems.box 页级相对整页，格级相对 frame；style 保存 fontFamily、fallbackFontFamily、fontSizePx、lineHeight、paddingPx、color、writingMode、textAlign。writingMode 为 horizontal-tb / vertical-rl，lineHeight 为正的字号倍率，其余尺寸为页面像素；字号 6–256、行距倍率 0.8–3。字体文件不隐式随 JSON 打包。
- bubble 保存 kind（none / rectangle / ellipse）、fillColor、borderColor、borderWidthPx、tail；tail 为 null 或 `{start,target}`，点相对该文字所属页 / 格。speakerInstanceId 可为 null，否则必须引用项目中存在的角色实例；跨格发声不要求实例在文字所属格。
- narrative.beatIds 去重且引用 StoryBeat。NarrativeGroup.beatIds 非空且去重；simultaneous 的 chronologyOrder 为 null，其它类型 chronologyOrder 恰好包含成员节拍一次。parentGroupId 为 null 或存在且无环的上下文组，timeLabel 是人类可读标签，不作为身份。时间组可以覆盖跨页节拍；嵌套表示叙事上下文，不强制父组直接包含全部子组节拍。
- 连续性链接 fromPanelId / toPanelId 必须不同且存在；subjectInstanceIds 引用实际角色实例。允许跨页关联，不因删页而保留悬空链接。confirmed 仅表示用户审核过当前关联；相关内容或布局修改后重置确认。
- characterInstances.instanceId 全项目唯一；复制 / 切分复制实例时生成新 ID，并重映射对白、尾巴发声关联和连续性引用。自动复制不沿用旧格的已确认状态。

## 7. 生成与导出交互（P0 / P1）

- 默认单任务并发，提供单格、选中格和当前页生成；任务中允许继续编辑其它格。
- 提交前固定每格有效配置；批量任务失败可逐格重试，不整页重新消耗生成资源。
- 状态为 queued / running / succeeded / failed / cancelled；进度不可伪造，后端未提供百分比时显示阶段。
- 取消撤下未提交任务；已提交任务按后端取消能力处理，界面区分“已请求取消”和“已取消”。
- 每格保存多个候选及其参数；新候选不覆盖已应用图，选取后独立确定裁切。
- 参数不兼容、模型缺失、服务离线、输出写入失败分别提示；写盘失败仍保留可恢复的结果引用。
- 生成默认值来自漫画项目，自成状态；复用纯工作流构建函数，避免修改全局创建页状态产生副作用。
- P0 页面 PNG 导出按真实页尺寸合成，包含裁切、格框、纸边、投影和已启用的基本文字 / 气泡；原图保留。未完成格导出前明确选择占位或取消，阅读箭头 / 选择虚线 / 网格不进入成品。P1 仅增加生成来源，不重复开发另一套合成器。
- 导出上限建议单边 8192px、总像素 32MP，采用主进程能力时仍需验证；超限提供降采样或分页，不导致画布分配崩溃。
- PDF、多页批量图、完整资产 ZIP 和长条分段输出作为后续能力单列，不能仅有按钮而无完整实现。

## 8. 工程边界与质量要求

- shared 放版本化类型、schema 与纯镜头常量；renderer 用 Zustand 管理编辑状态；main 做文件、原生能力和任务 I/O。
- renderer 不调用 Node / Electron；新 IPC 通道两端保持一致，入参校验，返回 IpcResult；主进程不向 UI 传堆栈。
- 功能建议独立在 `view/toolBox/Tool/comic` 或同域子目录，镜头数据与提示词编译分开，避免单一巨型组件。
- i18n 新增漫画功能命名空间，两种现有语言键一致；镜头名称与数据 ID 不耦合。
- store 更新和任务提交在事件 / effect 回调执行，不在 React render 中写外部状态。
- 页面级断点遵循 hydration 规则，后挂载浮层用 `useMediaQueryAfterHydration`；媒体查询“读取为准、事件为通知”，监听 resize / visibilitychange。
- 任何等待有超时；不以 rAF 作为文件保存、任务推进或关闭弹窗的唯一节拍。
- 视图切换 / 窄屏设置编辑不能触发第二套扫描、重复生成或丢失草稿；仅保留一份编辑数据源。
- 场景 / 图片缩略图加载失败有回退；原图引用变更释放旧 blob URL；长项目做增量更新和按需解码。

## 10. 开发前采用的默认决策

本版采用：先人工工作台、后图像生成、再 AI 辅助；常规混合页漫与异形跨格同属首期目标，页漫优先于长条高级能力。P0 包含基本文字与单页 PNG，P2 才增加高级气泡 / 音效。矩形、异形和撕裂自由混排，不把某一种格形强加给全部页面。手机统一设置与图层选择必须完整，远程生成不在默认范围。

P0 建议按五个可独立验证的增量开发：A 数据 schema / 保存 / 撤销；B 常规混合分格 / 共享边界 / 模板；C 异形边缘 / 多层叠放 / 取景；D 叙事路径 / 同图切片 / 基本文字；E 手机交互 / 单页导出 / 完整样页回归。每批保持项目可恢复，不用大范围一次重写来满足文档。

是否提前直接生成、远程生成鉴权、印刷与便携包规格仍需单独批准；这些选择不应阻塞 P0 普通编辑。此文档可作为开发拆解依据，但正式 schema、分格联动算法、字体渲染和性能预算仍须技术验证，不宣称已实现或覆盖所有漫画。

## 11. 代表性样页与交付物

样页使用项目自有 / 明确授权素材或占位图，复现用户参考的结构与阅读规律，不复制其漫画画面和文本。每个样页交付可恢复项目 JSON、关联资产清单、桌面 / 手机截图、1200×1600 或该页实际尺寸 PNG，并记录验收阶段、环境与结果。

| 样页 | 必须呈现 | 核对重点 |
| --- | --- | --- |
| S01 常规混合页漫 | 顶部大场景、右侧跨行竖格、两个人物反应格、下方对话格 | 参考图 3 的五格阅读路径；共享边界与文字位置 |
| S02 细节揭示 | 环境 → 道具细节 → 人物反应 → 真相 | 景别变化与节拍关联，不强制一段话一格 |
| S03 动作与撕裂 | 起势、反应、结果，加一格跨三格；普通格混用裂口 | 叙事顺序、图层、主体保护与随机轮廓恢复 |
| S04 回忆与并行 | 现在、回忆、同一时间两处行动 | 组关系、时间标识与阅读顺序分离 |
| S05 四格与基础条漫 | 四格节奏；有限长页中的停顿留白 | 顺序、格间距、手机浏览、导出上限 |
| S06 同图分格 | 一个连续环境被切成多个格 | 共享取景、接缝一致、脱组不跳动 |
| S07 文字排版 | 横排对白、竖排旁白、跨格文字、基本气泡与音效 | 文字顺序、实际字体、尾巴目标与溢出 |

验收先建当前格式的 golden 项目与 PNG，再验证旧格式迁移、坏引用及失败路径。仅原型画布截图不能替代正式项目导入 / 恢复；仅静态图不能替代真实交互；使用独立浏览器验证不能声称 Electron 应用冒烟通过。

最终项目资产与图片为并列交付：项目用于继续编辑，图片用于查看成品。只有 JSON 而无可解析图片资产不是完整可恢复交付；只有 PNG 而无项目也不是完成编辑器验收。

## 12. 开发前检查

- 需求：能力矩阵、交互与数据字段一一对应；P0 / P1 / P2 无互相矛盾承诺。
- 技术：联动切格、凹多边形、图像变换、同图切片、中文竖排与字体回退完成最小验证。
- 数据：shared schema 覆盖完整字段，最小示例及七种样页作为夹具验证；删除 / 复制 / 切分 / 合并 / 换模板均有引用检查。
- 交互：桌面及手机完整走通 S01 和 S03，确认最大化画布、不挤压设置、没有只能拖动的必需步骤。
- 实施：拆分模块和验证脚本，确定各增量验收项；正式开发前记录仍未通过的技术前提，不把文档状态当作测试通过。
