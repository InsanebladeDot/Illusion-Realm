## 1. 本轮目标与边界

把目前的静态工作区推进到能在真实 Electron 窗口演示的闭环：

**选择或拖入本地视频 → 素材面板更新 → 查看真实源视频 → 从素材区拖到时间线 → 选择、移动片段 → 验证界面同步。**

保持已确认的视觉、AppShell、三栏上区和底部时间线。复用 UI-02–UI-04 的组件，不能另建一张简化演示页代替正式入口接入。

| 本轮需要完成 | 本轮暂不接入 |
| --- | --- |
| 本地视频多选导入、真实元数据与封面 | 工程保存/恢复、导出、云端 |
| 文件系统拖入与逐文件反馈 | 图片/音频真实导入、真实音频波形 |
| 单个源视频的真实预览、播放/暂停 | 多轨节目合成、跨片段连续播放、音画混合 |
| 素材拖到 V1 创建片段，同源多实例 | 修剪、切分、转场、吸附、撤销/重做 |
| V1 片段选择、同轨水平移动 | 跨轨移动、加轨、轨道独奏/锁定业务 |
| 导入后列表、预览、片段头部与状态条同步 | 属性数值编辑、项目设置编辑、布局分隔条拖动 |

拖拽本轮特指三件事：**外部视频拖入、素材拖到 V1、V1 片段水平移动**。不要将“拖拽 UI”扩大为全部面板缩放、修剪和任意轨道编辑。

## 2. 正式入口与演示数据

- 正式路由仍为 `/tools/video/editor`，原版视频/GIF 工具接口保持兼容。
- 正式入口使用空的本地会话，明确显示「未保存」；空素材区提供导入按钮和拖入提示，预览显示未选择，时间线为空。
- 原来的 `scene_01` / `scene_02` 等确定性演示数据保留在现有 samples 或明确的演示入口，供视觉和 A/B 回归使用，不混进真实素材库。
- 空会话的项目预设暂为 1920×1080、30fps；这是项目设置，不是导入视频的探测结果。导入素材展示自身真实分辨率、时长和帧率，不静默改项目设置。
- 会话仅在本次页面生命周期内存在，离开页面即释放；离开前有片段时提醒「未保存，离开后将清空」。取消离开须保留当前内容，不假装已经自动保存。
- 导入不会自动创建片段；素材库与时间线是两层。项目时长按时间线最大结束时间计算，不把素材时长相加，也不继续显示固定的 30 秒工程。
- 空工程时长为零，但时间线视口仍可展示初始 0–30 秒的放置范围；视口范围与工程时长分开，不用零时长做坐标除数。

## 3. 导入与界面更新

### 3.1 按钮导入

1. 点击「导入素材」，打开现有系统视频多选选择器；取消不显示错误，不清除已有素材或选择。
2. 将选中的路径交给统一导入流程。逐文件校验并探测真实名称、时长、宽高、帧率和有无音轨，不能从扩展名或演示常量构造假数据。
3. 列表显示探测中、成功、失败状态；一个文件失败不回滚其他成功项。错误反馈包含可辨认的文件名与原因，不泄漏堆栈。
4. 提取真实视频封面。封面失败但元数据可用时显示缺图占位并允许使用；不回退成二次元样图或音频波形。
5. 相同规范化路径在会话内去重并告知；不同目录中的同名文件是不同素材，不能按文件名去重。
6. 导入期间锁定重复提交，显示文件级进度/数量；结束后恢复入口，失败项可重新导入。失败或取消不能把已有库变为空库。

首版每批最多 20 个文件，顺序处理或有明确的小并发上限，不一次创建 20 个解码器。可支持的扩展名沿用现有选择器；扩展名可选不代表 Chromium 一定能播放，探测成功与预览失败须分开报告。

### 3.2 外部文件拖入

- 编辑器工作区接收操作系统的视频文件拖放，显示明确高亮与「松开导入视频」提示；离开、放下或取消后高亮恢复。
- 拖入空白区域也可以导入，窄窗口素材栏收起时仍有入口；不能仅把接收区域放在隐藏侧栏。
- 使用现有 preload 的 `getPathForFile(file)` 获取真实路径，不依赖旧版 `File.path`，不让渲染层读取 Node API。
- 拖入与按钮选择最终调用同一个导入方法，去重、校验、错误、进度和资源清理完全一致。
- 非视频、文件夹、网页链接和纯文本明确拒绝，混合批次逐项说明；阻止文件落入编辑器后触发浏览器打开文件或页面导航。
- 外部文件落到时间线仍只进入素材库，不自动创建片段。需要用户再从素材区拖入，避免导入和编排行为混淆。

### 3.3 各区域同步规则

| 区域 | 导入或选择后的行为 |
| --- | --- |
| 素材区 R02 | 真实名称、封面、源时长；详情补充分辨率、帧率和音轨信息；沿用搜索/筛选，重名保留独立 ID |
| 预览区 R03 | 明确切入「素材预览」，播放所选的真实源文件；一次只有一个播放器 |
| 片段属性 R04 | 仅选择素材时不冒充已选时间线片段；选中片段后头部显示对应真实名称/封面，未接通数值编辑继续禁用，不展示 scene_02 的固定参数 |
| 时间线 R07–R09 | 仅通过拖入/添加创建真实片段实例；坐标来自起点与时长，不能按显示宽度反推并修改源素材 |
| 信息条 R10 | 项目预设和当前工程时长正确；源媒体 fps 与项目 fps 不混为一个值 |

搜索与筛选不能改变素材 ID 或自动选择首项。新导入项不满足当前筛选时提示其已导入但被筛选隐藏，并提供「清除筛选」；不要把导入成功误显示为列表没变化。

## 4. 真实预览的最小边界

- 选择素材可进入素材查看，片段选择保持不变；提供「返回节目」恢复先前工程视图。选中片段可查看它引用的源视频，素材列表高亮保持独立。
- 素材查看显示源时间和源时长；节目模式显示工程时间和工程时长。不能把一个源视频原生播放说成已完成时间线节目合成。
- 本轮允许单个源视频真实播放/暂停，使用真实媒体事件更新时间，不能定时增长数字伪造播放。播放失败给出可读提示与重试入口。
- 素材查看默认静音，声音由用户显式开启；切素材或片段、返回节目、隐藏播放器或离开路由时停止旧源播放，防止后台残留声音。
- 等比 contain，保留项目或源画面所需留边，横竖视频不拉伸。大文件不先读完整 Base64；优先现有 `localfile://` 范围读取与 URL 封装。
- 单源播放不推动工程播放头；它们属于不同时间域。返回节目后恢复原工程位置，不能把源视频的 5 秒写成工程第 5 秒。
- 节目合成播放、逐帧和帧导出继续禁用并说明原因。黑场、没有选片段、缺失文件、解码失败和加载中须分别处理。
- 显示编解码不受支持时保留已导入素材及元数据；不在本轮偷偷增加转码、代理生成或 FFmpeg 后台导出任务。

## 5. 素材拖到时间线与片段移动

### 5.1 素材 → V1

- ready 视频行提供拖动手势；拖动载荷使用素材 ID、当前会话身份和明确的操作类型，不传完整文件字节。
- 仅 V1 接受视频，A1/A2 显示不允许放置的反馈，不把视频悄悄转成音频。加载中或失败素材不可拖入。
- 落点按轨道内容实际矩形计算，包含当前横向滚动；轨道头、应用导航和侧栏的宽度不计入时间坐标。
- 拖动中显示片段轮廓、预计开始时间和是否允许放置；有效位置在松手时一次性提交，取消不产生片段。
- 新片段拥有独立 `clipId`，引用已有 `assetId`，默认使用完整源时长，起点为落点；同一素材可以重复拖入形成多个实例。
- 位置按项目帧率对齐。源长度向上取整到项目帧只是时间线占位换算，保留真实源时长；不能修改元数据或宣称发生了补帧转码。
- 新片段与同轨已有片段重叠时拒绝放置，保留原工程并给原因；不自动覆盖、挤开或切开原片段。
- 放置成功后选中新片段，更新片段头部和工程时长，不自动播放；素材选择不被片段选择反向覆盖。

### 5.2 V1 片段水平移动

- 拖动片段主体只改变该实例的开始/结束时间，不改变源入点、源时长、素材信息或同源其他实例。
- 保留鼠标抓取偏移，不能松手后将片段起点直接吸到鼠标位置而跳动。预览位置与最终提交使用同一个换算方法。
- 拖动期间固定秒/像素比例，仅按滚动量更新落点；不能每次预览右移就重新缩放整条标尺，导致片段追着鼠标跳变。结束后再更新工程边界与视口。
- 同轨移动，起点不小于零；重叠或其他非法落点时回到原位置并说明原因。移出窗口、取消或 Escape 不提交。
- 到达当前视口边缘时有限自动横滚，拖拽结束/取消/卸载均清理滚动计时器；不得无限请求 rAF 等待后台窗口。
- 轨道尺、片段和播放头读取同一时间范围；工程结束时间因片段移动而增长/收缩时同步更新，保证末端可见。
- 装饰性的两端把手仍无修剪行为，不设置可修剪鼠标形状。播放头拖动、缩放、吸附和跨轨交互继续待后续任务。

素材身份像货架上的原件，片段像借用原件的一张安排表：移动安排表不等于移动或改写原文件。数据模型须保持这两个身份独立。

### 5.3 无鼠标替代与交互冲突

- 素材选择后提供「添加到 V1 末尾」按钮，键盘可完成与拖入相同的创建流程。
- 片段聚焦后方向键左右移动一帧，Shift + 方向键移动一秒，遵守相同碰撞校验；不在输入文字时抢快捷键。
- 外部文件拖入、内部素材拖入和片段移动分别识别载荷，跨会话/A-B 实例或伪造 ID 均拒绝，不能默认查第一份同名素材。
- 业务失败通过就地反馈/status/alert 表达，不只改变鼠标光标；禁用控件保留原因和可见焦点。

## 6. 复用与实施约束

| 当前实现 | 要求 |
| --- | --- |
| `MediaPanel` / `MediaItem` | 通过 assets、状态、选择、导入和拖动回调接入；演示实例不因正式实例变为可用而共同发起文件读取 |
| `ProgramPreview` | 复用画布、状态和标题外壳；真实媒体生命周期独立适配，不把静态样板强制改为隐藏播放器 |
| `EditorClipShell` / `EditorTimeline` | 注入片段、坐标、选择和拖动意图；时间线不再直接绑定 `DEMO_CLIPS`，不复制另一套片段 CSS |
| `EditorAction` / `EditorPlaceholder` | 统一导入 busy、错误、禁用原因与焦点，不能另写无障碍较差的按钮替代 |
| `utils/video/ffmpeg.ts` | 优先复用 `pickVideoFiles`、`probeVideoFile` 与既有 FFmpeg 选择/探测能力；失败不静默回落成默认媒体参数 |
| preload `getPathForFile` | 拖入路径的现有入口；无需为取 File 路径另暴露 Node 或 ipcRenderer |
| `localFileUrl` / 现有媒体封装 | 复用本地媒体协议；旧单片段/GIF 状态机与新工程编排保持业务边界 |

实施前简述实际复用关系、参数差异与保留的独立业务。使用任务范围内的统一导入流程、共同坐标计算和共同碰撞校验，不能让按钮/拖入或鼠标/键盘分别实现一套规则。

媒体状态有独立拥有者，批次与会话有稳定身份；取消、切源和卸载后丢弃过期异步结果，结束 busy 并清理监听、播放器、缩略图 URL 和临时资源。所有等待有上限，超时显示失败，不靠永久等待维持 loading。

优先既有桥接；若确需扩展 IPC，按 `registerHandle`、`IpcResult<T>`、`INVALID_ARGUMENT` 和 shared/schema 等价校验同步实现。禁止渲染层导入 Node/Electron，禁止为演示创建另一套存储、全局 Context 或假成功回包。

### 必测用例

1. 两个真实视频：横屏和竖屏、不同帧率，至少一个带音轨；元数据与独立探测结果对照，文件名/封面不取样例值。
2. 按钮多选与文件系统拖入都更新正式工作区；取消、重复文件、同名不同目录、混合非法文件、损坏文件分别有明确结果。
3. 真视频产生实际可辨认画面、时间变化和播放/暂停；切源/离开不残留声音。探测成功但不支持解码与探测失败分开处理。
4. 素材多次拖到 V1 得到不同片段 ID；移动一个实例不影响同源其他实例。A1/A2、跨会话载荷、重叠和负起点被拒绝。
5. 时间线横滚后仍准确放置；选择/移动后名称、封面、工程时长与坐标一致；取消拖动不残留轮廓或改变原位置。
6. 键盘添加/移动与鼠标使用同一业务结果；素材选中与片段选中独立；筛选不会改写源媒体或片段身份。
7. 浅深主题、1600×1000 / 1280×800 / 960×720 容器，收起素材栏时仍可导入；导入中/拖动中缩窗或导航退出须能结束并清理。
8. UI-02–UI-04 样板和原版视频/GIF 相关入口无回归。原先“所有媒体动作均禁用、零探测”的断言只继续约束静态样板和未接通动作，正式导入须改为真实正向断言，不能简单删掉整组检查。
