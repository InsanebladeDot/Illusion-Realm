# 图片按住拖动与创作预览复用（2026-11-13）

## 用户行为与复用边界

在节点网预览中按住图片并移动鼠标即可平移，100%、缩小和旋转后均可操作；松开恢复抓手，重置或切图还原查看位置。拖动期间关闭变换过渡，让画面跟着鼠标走；缩放和旋转按钮保留原动画。

复用的是创作页 `ImagePreviewOverlay` 原有指针捕获、屏幕像素位移和拖后点击保护机制。抽出 `hooks/use-image-preview-pan.ts`，创作页原大图组件和节点网 `useNetworkView` 实际共同调用，删除了两处旧手势实现。创作页仍使用原 `ImagePreviewOverlay`、图片来源、切图和右键菜单；节点网仍使用原媒体与对比组件、main工具栏和底部资源条。

图片自身持有指针捕获，因此拖出图片仍能继续移动，图片单击不被误判为点背景关闭，双击重置继续有效。取消、丢失捕获、窗口失焦、页面隐藏、切图、关闭和卸载均结束当前手势；监听按实例安装和清理。关闭后组件仍挂载的创作预览，以会话键结束旧抓取。

位移只属于查看窗口，不写文件、节点坐标、撤销或生成参数。视频、音频控件与对比线继续处理各自手势；本轮没有修改创作页内嵌缩略图点击打开大图的入口，也没有替换两处业务外壳或全局主题。

## 失败尝试与修正

失败日志一并保留。节点网首次断言遗漏浏览器序列化的空格，之后的负数表达式拼接成了非法减减符号；修正测试表达式后38项通过。创作专项最初沿用只有列表路径而无实际文件的旧夹具，补文件时又发现Electron nativeImage不能解码该WebP，改为已有真实PNG字节；随后完善了“无过渡属性”和“重置动画结束”的测试等待，没有放宽位移断言或改产品动画时长来掩盖失败。
