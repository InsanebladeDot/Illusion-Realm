# 视频原组件侧栏与首页悬停

日期：2026-11-11。

## 复用与数据归属

视频只调用创作页原 `VideoModelSelect`、`VideoLoraSelect`、`WorkflowModelSettings`，放入图片已有 `CanvasImageSidebar` 外壳。没有搬入整个 VideoCreatePanel，没有第二份首尾帧、提示词、输出或生成按钮。

视频和图片在组件边界分开生命周期；视频不启动图片表单 store。模型覆盖新增 `videoModelOverrides`，分别记录 minimax / minimax-reference；主模型与 CLIP/VAE 复用原 loader 槽位覆盖。扩展继续原 workflowLoras，缺省继承，空数组明确清空。重置一笔事务只改当前节点与当前工作流，其他节点不变。

shared 与主进程执行等价严格校验；非视频拒绝视频覆盖，未知工作流、空槽ID、非法名称和超过64槽均拒绝。序列化顺序固定，不因表键顺序产生假脏。不新增IPC或存储层。

菜单使用原 CascadeMenu：本地 → MiniMax → 图生视频 / 参考素材生视频。画布暂不列 Wan2.2，新选项白名单不会删除全局注册或重写旧工程的 Wan 身份；旧设置仍明确说明能力限制。

首页入口移除嵌套 backdrop/filter 与 transition-all，用主题表面和明确过渡属性保留原悬停位移、阴影。品牌文字改用 text-shadow。此为渲染合成路径修正，不宣称已在用户原GPU上完成闪白前后对照。

## 验证与边界

视频侧栏专项8/8：仅三原组件、系列菜单无Wan、主模型和辅助槽回显、A重置不污染B、浅深主题、960窄窗、真实JSON保存重开。初始模型名称是参数夹具，未加载真实权重。离线模型清单显示原失败提示。

首页专项20/20：三入口两主题，每项8次25ms真实自动指针悬停采样，核对颜色、滤镜、命中与过渡；保留1500/900/390尺寸、导航、编辑及漫画原生dialog回归。自动输入不是人工鼠标或GPU视觉验收。最终日志与当前构建版本见 verification。

失败诊断保留：早期测试误点了和按钮同名的整个参数section，改为精确页脚button；公告遮挡先经真实关闭动作清理，不删DOM或绕过遮罩。没有通过改产品预期迁就测试。

阶段业务有效增量注释158/(158+67)=70.22%，测试236/(236+101)=70.03%。此审计冻结于后续名称任务前；工作区快照基线中 picker 的早期快照为依据已知补丁反向重建，不能冒称原始字节快照，其余为当时实际文件快照。统计与样本见 runtime 审计JSON。

仍未接视频生成、真实权重验证；原有人工待验、系统DPI、读屏和GPU复测继续保留。
