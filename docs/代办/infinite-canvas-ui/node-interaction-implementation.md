# 无限画布：节点微交互修复

日期：2026-11-06。范围限于用户四张参考图的五项 UI/手势问题。正式入口 `/canvas`，保留已有未提交性能修改。

## 实现与复用

| 需求 | 实现与边界 |
| --- | --- |
| 展开箭头旋转 | 沿用 `CanvasIcon` 的右向 chevron；`aria-expanded` 与真实面板共用 `panelOpen`，展开顺时针转 90°，收起回到 0° |
| 端口轻微跟随 | 原 React Flow Handle 固定，内部圆圈与加号为视觉 span；端口边缘外 20 屏幕 px 范围内跟随，总位移最多 15 屏幕 px，按镜头 zoom 换算 |
| 连接受力效果 | 订阅现有拖线/点击连线状态的布尔值，接近输入端时仅内容板做 CSS 透视旋转；横向 -2.5°、纵向最多 ±2°；标题、参数和锚点不旋转 |
| 极浅细选框 | 沿用原主题机制，节点常态/选中使用独立语义色，1px 且去掉第二圈阴影；不改变通用按钮、文字或媒体像素 |
| 短按与搬动区分 | 捕获左键按压，250ms 或屏幕移动至少 4px 判为搬动；松手再次核对距离，长按/拖动不打开参数，右键与控件排除。显式箭头折叠仍保留，新增节点仍可立即编辑 |

`CanvasNodeCard → CanvasNode`、`GenerationPanel`、`CanvasIcon` 与两侧真实 Handle 继续共用；没有新增“导入节点版”或复制参数面板。kind、data、selected、端口方向和业务回调仍由原调用方注入。文字、图片、视频、音频均接入同一适配；便签和合成器保留自己的入口与业务。

新增 `use-node-press.ts` 管理本卡按压意图，`use-port-motion.ts` 管理局部展示偏移；选择仍归图库，保存/撤销仍归原 reducer，播放器清理仍归媒体组件。短按意图与显式折叠分开，搬动不会被误算成输入操作；鼠标和键盘展开执行相同动作。

Enter/Space 明确激活真实控件并阻止父图库抢先处理，防止按钮失焦漏点；默认激活被阻止以免二次触发。Tab 和方向键保持原路径。

## 生命周期与性能边界

- 不捕获指针、不阻断原拖动；通过指针编号关联按下与松手，移动判断不写工程坐标。
- 长按定时器只识别手势，取消、Escape、失焦及卸载清理；它不模拟任务或媒体进度。
- 跟随直接写本端口 CSS 变量，不逐像素更新 React 状态；只测当前 Handle，不扫描全图。连线订阅不读取每像素末端位置。
- 连线结束、移开、失焦、减少动态及卸载回正并拆监听。镜头倍率仅调整命中范围与显示长度，不改节点尺寸或资产引用。
- 减少动态沿用现有媒体查询 Hook；CSS 去过渡，JS 停止实际跟随/倾斜，箭头保留静态朝向。
- 无新 IPC、工程字段、文件权限、依赖或媒体会话。大量节点/GPU 开销未专项测量，不把本轮微交互回归作为大工程性能承诺。
