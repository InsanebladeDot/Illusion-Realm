# 文件前缀、图片引用标签与实际改名

日期：2026-11-11。

图片与视频节点提示词直接共用创作页 ImageReferencePrompt，图片不再另用一份不支持 @ 的 textarea。候选及已插入标签显示实际文件主体；封面固定20×20 CSS像素。图片节点左上标题也读取同一主体，空图片节点仍使用用户工作标题。

引用装饰通过独立显示属性呈现名称，正文保留 @pictureN。服务提交继续规范 Picture 协议，两个同名文件不会按显示名串图；资源顺位继续由上游节点稳定ID决定。标签为不可编辑整体，光标恢复到标签前后，缩略图不改变原图内容。

双击标题进入草稿，Enter/失焦提交，Escape恢复。真实图片调用原图库 renameGeneratedImageOnDisk，保留原后缀、正文与既有元数据处理，不新增任意文件IPC。适配时附回原扩展，解决旧接口剥掉“人物.正面”最后一段的问题。

成功改名后一次 reducer 分派同步当前节点、同源节点、手动输入、past、future、drag和clipboard，再交原用户文档保存器。磁盘改名不伪装成可撤销；其他编辑撤销保持有效的新媒体地址。跨工程共享外部路径不做全盘扫描修复。保存失败保留真实新路径及原保存错误，支持原入口重试；当前未建立文件改名与用户JSON之间的跨文件原子事务，进程中断、磁盘满、ACL或旁车移动失败未做故障注入验证。

## 实际验证

纯生产源码回归61项，新增反证覆盖文件主体优先、空上游标题、手动输入、旧状态不变、无关同名路径保持、全部历史和剪贴板重定向。

正式Electron图片生成与名称集成21/21：真实PNG改名、旧路径消失、新文件字节相同、同源卡和手动引用保存、Escape取消、真实同名目标拒绝、重开图片节点 @ 标签与已解码方形缩略图。生成传输仍为夹具，不是实际模型推理。图关系初始化和DOM双击属于自动事件，未声称人工实体操作。

初轮失败真实暴露含点主体被原接口截短，修正调用参数后完整重跑通过，保留首轮日志和故障截图。重开图片夹具位置后移，避免参数区左边缘截断证据；没有修改产品碰撞或布局规则来迁就截图。

增量业务242/(242+102)=70.35%，测试225/(225+96)=70.09%。基线是名称请求开始前工作区实际快照，新增文件全文计入；纯注释去重、混合行计代码，人工复核解释职责、名称例子、索引重定向与错误边界。普通逻辑函数审查无超过30有效行的新问题。

未验证：实体IME/读屏、系统剪贴板全流程、系统DPI、跨工程外部改名监听、大工程长时性能、系统文件操作故障恢复。此前人工项不改写为通过。
