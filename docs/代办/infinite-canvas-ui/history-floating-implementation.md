# 图片管理单行浮动操作条

日期：2026-11-11。

全选、取消、移动、删除的原按钮直接作为 children 复用，选择、确认、错误与文件操作仍归原图库。新增 HistorySelectionToolbar 只负责几何：原 sticky 区保留48像素锚点，按钮通过 body Portal 与原生CSS锚定脱离父级裁切；保持单行，极窄时只在工具条内部横滚。

每个实例使用独立锚名，卸载清理Portal，没有逐帧React测量或额外文件状态。不可见锚点隐藏对应工具条；后台保活页面的完整键盘不可达性尚未专项人工核验。

真实文件移动、重名冲突、旁车、取消、排序、改名与重开专项31/31，最终运行版本与截图见 verification。`history-move-dark-narrow` 旧文件名不代表实际深色，复核画面为浅色；不将其当成深色证据。

业务有效增量42/(42+18)=70.00%，测试15/(15+4)=78.95%。以单行浮动请求开始前工作区快照统计新增替换行，排除其他图库既有修改；注释说明Portal与锚点职责、极窄滚动和原按钮业务归属。

不新增图片上传、外部文件监听或独立文件管理状态。人工系统框、实体拖入、键盘全路径与DPI仍待验。
