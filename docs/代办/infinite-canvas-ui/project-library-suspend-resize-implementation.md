# 工程库、挂起与节点尺寸（2026-11-12）

状态：实现已接通，自动验证记录见下文；人工操作待验。保留本轮开始前的工作区修改，不提交或上传 GitHub。

## 使用方式

- 点击导航“无限画布”先进入画布工作区。支持新建画布、搜索、新建分类文件夹、多选、全选、取消、批量归类和删除。空分类才可删除。
- 编辑器左上角品牌图标打开工程菜单：挂起返回、关闭返回、重命名、删除。导航显示挂起名单，可切回或关闭。
- 挂起先保存，保留当前编辑器、撤销历史和在途生成。关闭先保存再释放实例；生成或文件操作未结束时拒绝关闭，不假装已停止后台任务。
- 图片、视频、音频、文本、便签、场景和合成器节点共用四边与右下角缩放。没有四周蓝线或方块，边缘仍有方向光标。缩放只改变卡片尺寸，不改媒体像素、生成分辨率或导演台内部构图。
- 选中后右键“固定尺寸”/“解锁尺寸”只控制节点缩放，不禁止移动、文字编辑或连接。
- 画布设置 → 节点与布局 → “固定所有组件尺寸”，复用原设置开关。开启会恢复所有节点的类型默认尺寸，并禁止缩放；关闭不会找回被清除的自定义尺寸，但可用原撤销恢复。单独尺寸锁继续保留。
- 固定规则进入同一业务更新入口，尺寸菜单、拖动、导入、粘贴和生成回填不能绕过全局固定。锁与全局开关均随工程保存。

## 复用与状态边界

| 入口 | 复用实现 | 独立数据 |
| --- | --- | --- |
| 所有节点缩放 | 原 React Flow NodeResizeControl、节点外壳、坐标及拖动事务 | 每节点 card / resizeLocked |
| 尺寸设置 | CanvasSettings、CanvasSwitch | 当前工程 fixedSize |
| 工程菜单 | 原 CascadeMenu、CanvasOverlay、CanvasChip、确认表单样式 | 当前 session / projectId |
| 工程读写 | 原 SQLite Worker、原子表、校验及反读核对 | 每工程 project.sqlite |
| 多画布挂起 | 原 InfiniteCanvasPage / ReactFlowProvider / 生成 Hook | 每实例图、历史、表单、媒体状态 |

会话名单用 Zustand；图内容仍由原编辑器管理。常驻宿主读取真实 main 容器矩形，导航开合不手拼固定偏移。隐藏实例 inert，移除交互浮层、拒绝快捷键并暂停自身试听；挂起没有克隆编辑器或取消生成。退出整个应用会释放挂起名单，重开从磁盘恢复已保存作品，撤销栈不跨应用重启保存。

连接端口与缩放热区交叠时端口优先，避免透明边缘吞掉原有跟随及连接；上下边和角的缩放仍可用。

## 磁盘与原子表

`user` 指现有用户文档所在目录，沿用用户自定义位置。

```text
user/
  illusion-realm.json               设置、账户偏好等原有数据
  illusion-realm.sqlite             原有已迁移业务及旧画布备份段
  Infinite Canvas/
    library.sqlite                 工程目录表、逻辑分类
    .legacy-imported               首次旧草稿完整迁入后才写
    .legacy-pending.json            中断迁移的固定目标身份
    <工程名或唯一目录>/
      .canvas-owner                工程归属标记
      project.sqlite               当前工程的原子化图数据
      Picture/                     受管图片
      video/                       受管视频
      Audio/                       受管音频
```

分类文件夹是数据库中的逻辑分类，不是搬动媒体的实体目录。改分类不搬大文件；工程名称改动也不重命名稳定的受管目录。导入工程包或跨工程引用可以保留另一受管素材目录，便携导出继续收集实际引用。库缩略区目前显示节点计数图标，不冒充实际工程截图。

SQLite 迁移003只追加结构，旧001/002不改写：总表数46、版本3。目录数据库与每个工程数据库沿用同一迁移器；作品数据继续拆在原子表中，不新增整图 JSON blob。

| 分类实体 | 工程目录实体 | 作品实体 |
| --- | --- | --- |
| `canvas_library_folder`<br>folder_id、name | `canvas_library_entry`<br>entry_id、directory、name、folder_id、updated_at、node_count、deleted | `canvas_state`<br>原字段 + fixed_size |
| 一分类 → 多工程<br>folder_id 外键 | entry_id 对应 owner 与独立数据库<br>软删不被目录扫描复活 | 一个工程 → 多节点/连接<br>沿用既有外键 |
| 空分类可删除<br>非空 RESTRICT | `deleted=1` 从库移除<br>不删除工程或媒体文件 | `canvas_node_detail.resize_locked`<br>其余 node/edge/media 表沿用 |

删除是软删除：列表移除、普通 load 拒绝，目录及素材保留，避免其他工程引用损坏。当前没有恢复/清空回收站 UI，也不会释放所占磁盘；确需恢复时应先备份目录和库，再按 entry_id 恢复目录表标记，不能删除库文件来假装恢复。

旧草稿首次打开自动迁入：复制自有目录、逐文件 SHA256 校验、重写媒体及外嵌工具引用，再保存和反读核对，最后写完成标记。原 SQL 草稿和原文件保留。失败重试使用同一 pending 目标，不反复复制新工程；符号链接、路径逃逸、归属不符拒绝。**本轮只在隔离临时目录验证迁移，未运行真实用户目录搬迁。**

## 验证与证据

运行命令、结果、失败和最终截图以 [verification](verification.md) 本轮条目为准。测试采用正式静态导出 `app://`、生产 preload、实际 SQLite 和文件服务，Electron 串行执行。截图来自运行窗口，操作由自动 DOM 事件和 Electron 输入注入，不写成人工通过。

故障修复包括：IPC 可选值 undefined 在旧 JSON 路径会被省略，而直接 SQL 反读严格比较会失败，现于工程保存边界归一化；删除确认与新建表单接入原确认外壳；缩放热区不再遮住连接端口；远端图片生成服务同步使用 Infinite Canvas 素材根，保留原归属校验，避免已有工作区身份在旧根下找不到。测试同步适配正式工程库入口、SQLite 独立读回和保存失败注入，不以旧用户 JSON 的画布段作为新正式工程的权威结果。

## 限制与未验证

- 人工鼠标手感、完整实体键盘路径、资源管理器拖入、扬声器试听、Windows 系统缩放未实测；先前待验项不改成通过。
- 真实付费模型和本机真实 ComfyUI 推理未验证；HTTP/返回值夹具只证明请求、回填和保存接线。
- 未做大规模工程列表窗口化、挂起实例数量限制及内存压力测试。挂起会保留图与媒体 DOM，数量增多会增加内存；目录发现会逐个检查未登记的工程。
- 没有新增分布式多窗口同时编辑同一工程的冲突合并，也不宣称支持多进程并发写入同一草稿。
- 安装器及跨机器便携恢复未测试；asar 验证只证明 SQL 资源和 Worker 能从归档加载。
