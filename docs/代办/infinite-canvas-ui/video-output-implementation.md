# 视频输出配置与创建模式悬停

日期：2026-11-11。仅接输出意图与局部交互，不开放视频生成。

视频与图片直接共用 ImageRatioPicker、OutputQualityPicker、CustomSize、ParameterPopover、CanvasChip；视频注入短边档位与偶数步进，图片保留长边1K/2K及八像素步进。视频480p、720p、1K分别按短边480、720、1080计算，1K按用户明确确认解释为1080p。横屏16:9对应854×480、1280×720、1920×1080，竖屏交换宽高；自定义明确输入两个像素边长。旧节点显示默认720p，浏览时不补写默认字段。

用户已明确确认“帧数”指每秒帧数 **FPS**。现有实现提供24、30、60、自定义正整数，缺值显示24 FPS；与用户确认的定义一致。时长提供2、5、10秒和自定义一位小数，入口显示x.x秒，缺值5.0秒。帧率、时长复用同一 VideoNumberPicker 和原参数浮层，自定义草稿Enter/应用确认，Escape丢弃草稿、返回触发焦点；非法值就地提示且不改确认参数。

videoOutput、videoFps、videoDuration均为节点独立的optional纯数据，进入原JSON保存与规范序列化。shared与主进程等价严格校验，拒绝跨节点类型、额外尺寸字段、奇数宽高、非法FPS和时长；旧version=1缺字段仍兼容。不新增IPC、不重编码或更改源素材，不给未接通的模型能力报成功。执行器未来仍需校验具体服务支持的比例、分辨率、FPS、时长和总帧约束。

创作页顶部四个标签仍用原CreateModeTabs → IconTabButton。仅将data-create-mode-tabs排除在通用按钮hover描边之外，局部hover改变文字和currentColor图标，保留实际选中状态、原选中背景与条底下划线。键盘focus-visible继续可见，素材分类和其他按钮不受本局部规则影响。
