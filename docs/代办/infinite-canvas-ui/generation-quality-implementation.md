# 图片请求、画质与调度器

日期：2026-11-11。追加实现，早期“生成禁用”记录保留为历史，不代表当前图片状态。

## 实现与复用

节点唯一请求按钮接入原图片生成队列、文字改图队列和 Euzhi 适配器。单图回填原节点；多图保留原节点并建立 n−1 个独立结果节点，整批一次撤销。失败、取消保留既有内容，取消绑定本次任务身份。

图片侧栏直接调用创作页 `ImageCreatePanel variant="settings"`，保留反向提示词、高级设置、主模型、扩展与模型加载。提示词工具默认前四项，额外入口展开其他原工具；批量入口显示 ×n，不新增第二份数量状态。节点之间与不同工作流的参数分别保存。

画质复用原参数悬浮外壳：1K 长边1024、2K 长边2048，短边按比例并按8像素约束对齐；自定义保存明确像素宽高。比例、画质和实际请求尺寸共用计算。Euzhi 尚仅确认1024方图与 medium，远端2K/自定义保持明确禁用，不伪装成服务支持。

公共调度器列表为 simple、sgm_uniform、karras、exponential、ddim_uniform、beta、normal、linear_quadratic、kl_optimal，默认 simple。创建页与画布共同读取原配置。

上游图片按稳定数字节点身份排序，手动导入后置，空上游仍保号；提交继续使用规范 Picture 编号。后续的文件名显示与图片 @ 输入补齐见 [名称与引用实施](media-reference-name-implementation.md)。

## 证据与限制

最终结果统一见 [verification](verification.md)。真实 Electron 使用正式静态工作区与生产 preload；本地服务通过 HTTP 夹具返回真实可解码 PNG，远端只替换传输返回。它们证明请求、取消、回填、保存与 UI 接线，**不证明真实 ComfyUI/Euzhi 推理、计费或模型语义质量**。

视频请求仍未接通。没有新增视频保存、导出、混音或多轨播放。真实服务、系统选择框、实体拖入、IME、读屏、系统DPI和长时压力保持未验证。

阶段增量业务注释879/(879+362)=70.83%，测试797/(797+341)=70.04%。统计冻结于追加视频配置前，以请求开始前工作区快照为基线；后续阶段单独统计，不能叠成全仓注释率。排除定界符、重复说明和混合行重复计数，人工核对职责、事务和证据边界。示例：用“按座位号发节目单”解释稳定资源顺位；取消注释解释为何只中断本次任务。

证据目录：`runtime/generation-quality-2026-11-11/`。旧全创建页失败四项及未完整基线A/B的限制仍在 verification 保留，不写成全仓全部通过。
