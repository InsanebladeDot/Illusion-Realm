# 帧率横向选择与下划线输入

2026-11-12，正式无限画布视频节点。

帧率菜单改为 **10、20、25、30、60、自定义** 一行显示，入口仍显示实际数值及FPS单位。已有24 FPS默认/保存值保留，只有主动选择才改变参数。自定义只显示一个数字输入框，透明背景、无圆角，仅下边线，不再提供应用按钮；回车或失焦提交，Escape取消。小数、零和空值仍由原步进校验拒绝，不污染确认参数。

复用关系：`VideoNumberPicker` 同时服务帧率与时长；预设、格式、单位和步进通过参数注入，草稿、取消标记及已确认数值按实例隔离。菜单直接使用原 `SegmentedControl` 和 `ParameterPopover`，与图片比例条共用横向、文字高亮及主题规则；`hy-ratio-popup` 的黑/白表面成为共同样式，去掉灰色双层菜单。时长仍是2/5/10及小数自定义，没有把帧率预设或整数限制套到时长上。

自定义确认有两道事件保护：Enter之后的失焦不重复提交；Escape先标记取消，再由原壳关闭还焦点。点击另一预设时让该按钮完成确认，不先提交旧草稿并卸载按钮。原浮层外部点击先派发真实失焦再卸载，避免合法自定义因DOM先移除而丢失。关闭和清理由原壳维护，没有新增全局数字状态或另一套浮层。
