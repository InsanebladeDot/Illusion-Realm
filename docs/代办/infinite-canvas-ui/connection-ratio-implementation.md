# 图片拖线创建与创作页比例复用

日期：2026-11-11。只完成图片输出拖空白创建两类生成节点，以及图片/视频比例共用创作页静态参数。

图片节点输出端拖到画布空白后，复用原 AddNodeMenu，菜单只显示“图片生成”“视频生成”。确认后在松手世界坐标创建新节点并连接来源。图片目标使用既有 ANIMA 图片编辑·文字改图流，符合单图输入限制；视频保留既有 MiniMax 默认。菜单本身不发起生成、不复制上游媒体作为输出。关闭、Escape 或源已失效均不留孤立卡；节点与边是一笔原编辑器事务，可一步撤销/重做。

## 复用与边界

| 部分 | 原实现与本次接入 |
| --- | --- |
| 比例静态源 | `packages/shared/src/data/imageSizes.ts` 的 IMAGE_SIZE_PRESETS；创作页图片、视频与画布图片、视频读取同一份表 |
| 比例 UI | 原 ImageRatioPicker → ParameterPopover → SegmentedControl；八项原顺序，纵向列表，内部有高度上限 |
| 添加 UI | 原 AddNodeMenu 注入图片来源变体，只保留两个有效目标；普通完整添加菜单不变 |
| 世界坐标 | 原 React Flow screenToFlowPosition；不手算导航偏移或缩放 |
| 图与历史 | 原 editor.add 与 canvasReducer.add、connectionError、commit；新卡与边统一校验和提交 |
| 保存 | 原 serializeCanvas、shared schema、主进程校验、用户 JSON 和工程归档；未新增 IPC 或存储层 |
| 侧栏回写 | 原 isAspectRatioLabel 支持全部创作页比例，不再仅允许旧四项同步到页脚 |

八项为 1:1、2:3、3:2、3:4、4:3、5:6、9:16、16:9，显示 label 直接取原参数。工程仍保存斜杠形式，例如 5/6；旧 version=1 与旧四项无需迁移。主进程 CommonJS 保留等价手写允许集，由生产 schema/主进程对照测试守住一致，不运行时加载共享 TS。

只复用比例身份与顺序，不把 SDXL 训练分桶像素强加给输出画质。图片仍按 1K 长边1024/2K长边2048计算，视频仍按480p、720p、1K=1080p短边规则计算，自定义和远端供应商能力边界不变。视频生成执行仍未接通，真实供应商/权重支持范围不由静态选项保证。
