# 创建页参考图 · HTML + Tailwind CSS

2026-10-21。独立页面样例，未接入产品代码。`twindcss` 按项目所用的 Tailwind CSS 实现（本机编译版本 4.3.3）。

## 打开页面

- 直接用浏览器打开 `index.html`。CSS、JavaScript、WebP 图片和 SVG 图标全部内嵌；离线可用，无 CDN、外部字体、框架运行时或构建要求。
- 从仓库根目录运行 `node docs/待办/资源/anime-create/serve.cjs`，访问 <http://127.0.0.1:4179/>。
- 仅本机开放预览，不对公网发布。端口被占用时，确认已有预览服务后复用，不终止未知进程。

## 文件与编辑方式

| 文件 | 用途 |
| --- | --- |
| `index.html` | 可直接运行、分享的最终单文件 |
| `source.html` | HTML 结构和 Tailwind utility 类；`CSS` / `SCRIPT` 为编译插槽 |
| `styles.css` | 组件样式、尺寸、主题变量、响应式规则 |
| `interactions.js` | 页面本地交互，无后端请求 |
| `build.cjs` | 裁切参考图、处理透明立绘，编译真实 Tailwind，再内嵌所有资源 |
| `serve.cjs` | 只提供最终 HTML 的本地 HTTP 服务 |
| `verify.cjs` / `verification.json` | 浏览器检查脚本和结果 |
| `assets/reference.png` | 用户提供的原始参考图，1566 × 1004 |
| `assets/*.webp` | 主图、侧栏插画、头像、模型封面、缩略图和文件图 |
| `desktop.png` / `desktop-dark.png` | 实际浏览器渲染，1566 × 1004 |
| `mobile-edit.png` / `mobile-preview.png` / `mobile-files.png` | 手机视图，390 × 844 |
| `tablet.png` / `generation-demo.png` | 平板图库浮层与演示结果 |

修改源文件后，在仓库依赖已安装时运行：

```powershell
node docs/待办/资源/anime-create/build.cjs
node docs/待办/资源/anime-create/verify.cjs
```

重建使用项目已有的 Tailwind 和 Sharp。最终 `index.html` 不需要这些依赖。浏览器检查脚本使用项目已有的 Edge CDP 辅助程序，需要本机安装 Microsoft Edge；不会操作日常浏览器资料。

## 视觉与布局

保留参考的“导航 → 创建表单 → 预览 → 文件管理”顺序、蓝紫配色、主图比例、轻边框与渐变生成按钮。文字、按钮、输入框均是真实 HTML，没有用整张截图冒充页面。

| 视口宽度 | 行为 |
| --- | --- |
| ≥1450px | 完整四栏，导航 204px、表单 350–464px、预览弹性、文件管理 336px |
| 1180–1449px | 导航收为图标，表单和文件管理适当收窄 |
| 821–1179px | 导航、表单和预览常驻；文件管理从顶部按钮打开浮层 |
| ≤820px | 编辑 / 预览 / 文件分视图展示，单栏独立滚动 |

生成按钮固定在表单底部；短窗口内滚动表单内容，不通过整体缩小字号腾空间。手机输入框字号 16px，避免输入时放大视口。字号、边框、焦点和间距由统一类与变量维护；支持减少动态效果偏好。

## 图像来源与限制

左侧角色与文字使用用户提供的项目资源 `apps/next/src/assets/icon/Nav/role.png`（1254 × 1254，RGBA）。构建时去除外围透明留白，缩放为 440px 宽的无损 WebP，并保留透明通道。没有背景铺底、渐隐遮罩、混合模式或深色主题降透明度处理；浅色与深色主题显示同一张立绘。

其余位图从参考截图裁切。主图裁切为 479 × 468；缩略图仅 68 × 57，文件列表图约 63 × 62。缩略图切换为大图后会模糊，这是原始截图分辨率的限制；产品接入应替换为原始高清图片。模型封面为截图局部，放大后也有清晰度损失。

裁切坐标集中在 `build.cjs` 的 `crops`，方便替换素材。`assets/sidebar.webp` 是透明立绘的预览副本，最终 HTML 内嵌该资源，离线查看不依赖项目路径。
