# 模型默认可选，使用后再判断

此前将 `/models` 没有列出的型号标为不可用。该列表可能不完整，导致实际上能调用的 GLM 模型变灰。

现在所有目录型号默认可选，显示“可选 · 使用时验证”。只有实际请求明确返回模型不存在、模型未开通或模型权限拒绝时，才将对应型号置灰。网络超时、限流、欠费、认证失败、服务故障和图片参数拒绝不会单独封住模型。请求成功后显示“最近调用成功”。

Agent 和转译共用 `provider-model-availability.js` 的登记逻辑，继续直接复用原 `AgentModelDialog` 和 `AgentModelCard`，没有复制卡片或弹窗。请求结果按供应商、密钥指纹和型号区分，仅留在当前进程内存；价格缓存不保存权限结论，也不保存密钥。

点击“刷新列表”、重新登录或重启应用后允许重新尝试。登记按请求发出时的配置快照写入；同型号的较早请求或刷新前的请求迟到，不会覆盖新结果。更换密钥也不会继承另一把密钥的失败记录。
