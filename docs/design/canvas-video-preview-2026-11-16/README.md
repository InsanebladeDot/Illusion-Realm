# 画布视频铺满与窗口内预览

导入的视频默认铺满节点卡片，保持比例并裁切多余边缘；不会修改视频文件。右下角放大按钮打开现有节点网大预览，占满软件主显示区，保留应用标题栏与导航，不再调用浏览器或系统全屏。大预览完整显示视频画幅；按Esc或关闭按钮返回。

## 实际复用

原视频控件通过 `onExpand` 通知卡片，卡片以自身节点ID交给工作区。工作区的 `openPreview` 同时服务双击和视频放大，继续使用 `CanvasOverlay`、`CanvasNetworkPreview`、原播放控件、媒体清理与焦点恢复。大预览内不再提供重复的系统全屏入口；没有另写一套视频弹窗。

图片卡片原有铺满及大预览完整适配保持相同规则，音频仍使用自己的波形与播放布局；素材、工程保存和生成请求不变。
