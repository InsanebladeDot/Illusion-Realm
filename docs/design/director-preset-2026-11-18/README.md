# 导演分镜预设、全文复制与调度器裁切修复

本轮只处理三项：加入用户提供的完整导演分镜提示词，点击预设复制完整指令，以及调度器下拉列表被父容器截断的问题。保留工作区此前的修改。

## 使用结果与复用

- 提示词助手 → 预设文本新增「专业导演 · 分镜设计」。中文正文共 3902 字符，保留原文全部章节、分镜表、模板和示例，仅去掉聊天里的转义符。英文目录提供对应指令。
- 内置、自定义预设共用同一个选择与复制回调：点击预设会选中、保存并复制完整系统指令。复制失败显示「复制失败」，选择行为继续保留。编辑自定义预设的入口不触发复制。
- 预设目录、请求指令和历史名称继续使用 `PROMPT_PRESETS` 与现有读取方法，没有另一套转译请求。
- `OptionSelect` 改为直接复用现有 `SimpleSelect` 的 Portal 模式。定位、上下展开、滚动、键盘、关闭及清理均由公共组件负责，不再保留另一份下拉实现。
- 新增可选 `fallbackLabel`，工作流中保存的旧值即使不在当前清单中，也显示真实值。悬浮选项提交前检查原按钮的实际禁用状态，不能绕过父级 `fieldset` 的禁用。
- 采样器、调度器及原来使用 `OptionSelect` 的编辑选择器同时接入。业务值、保存回调与工作流参数不变。
