# 任务卡片实时耗时

原任务卡片的时间区域现在每秒刷新“耗时 xx.x 秒”。图片、视频、音频复用同一个卡片和显示逻辑；从原队列的实际 `startedAt` 开始计时，不包含等待时间，也不代表已经生成的媒体时长或预计剩余时间。

关闭任务面板后停止界面刷新，任务照常运行；重开根据实际开始时间计算，不从零开始。完成、失败或取消后使用原 `finishedAt` 固定耗时。旧任务没有开始记录时不猜测。只改显示，不向任务状态或SQLite每秒写入，不改变生成和取消流程。

复用 `GenerationTaskCard`、原时间词条和主题样式。新增 `use-generation-task-elapsed.ts` 管理局部刷新及卸载清理；原时间区域中不再适用的长注释替换为两句实际规则。
