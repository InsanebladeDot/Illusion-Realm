# 首页入口与软件图标

主窗口正式入口由 `app://app/index.html` 改为 `app://app/`。原协议已支持根地址读取首页文件，无需新增重定向。旧窗口仍在 `/index.html` 时，面包屑复用首页名称、图标和用途，保留实际历史记录，不增加一次跳转。

软件图标采用用户提供的透明 PNG。原图保存在 `apps/electron/assets/icon-source.png`；现有构建要求运行图标为 256×256，因此等比缩放到 `icon.png`，完整保留构图和透明背景。Windows ICO 继续由原构建脚本生成，窗口、客户端 EXE 和 Setup 外壳沿用现有资源路径。没有重新打包或改写已安装程序。

图标检查确认原图副本字节一致，PNG 与 ICO 解码像素一致，并保留透明通道。主进程类型检查、路由元数据检查、渲染定向 lint 和静态构建通过。正式静态页面导航回归 **31/31**，覆盖根入口、旧入口、旧入口返回、前进后退、用途提示、双语与窄窗口。截图见 [首页](home-entry.png)，过程见 [navigation.log](navigation.log)。未验证重新安装后的 EXE 图标或 Windows 旧快捷方式缓存。

本次保留工作区此前修改，注释统计仅计本轮新增及替换行，二进制资源不计。业务 C=2、B=2，50%；测试 C=1、B=15，6.25%。改动很小，注释只解释入口映射和历史边界，不为比例补说明，明细见 [comment-audit.json](comment-audit.json)。
