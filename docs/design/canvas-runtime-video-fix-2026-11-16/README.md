# 画布刷新报错与视频节点手势修复

## 原因与改动

`removeChild` 已在“修改样式 → 保持窗口打开 → 刷新 → 继续打开预览”中复现。完整调用栈指向 Next 16.2.10 自带的 `mini-css-extract-plugin/hmr/hotModuleReplacement.js`，并非业务组件删除视频。它等待新样式加载后再删除旧链接，但旧链接可能已经被另一轮更新移除。

`patches/next@16.2.10.patch` 只把这个模块加载成功、失败两个回调里的删除改为可重复执行的 `Element.remove()`。新样式的安装、错误事件和热更新仍照常执行；没有拦截全局异常，也没有修改 DOM 原型。补丁由 `pnpm-workspace.yaml` 登记并锁入 `pnpm-lock.yaml`，重装依赖继续生效。补丁正文与登记配置也加入构建指纹，避免改补丁后误测旧产物。Next 升级时须重新核对是否仍需要补丁。

回归还发现：异步画布模块中的 React Flow 全局样式可能在热更新后丢失，节点从绝对定位退回普通文档流。该样式现统一由 `app/layout.tsx` 加载，并删除原异步模块里的重复入口；应用样式仍在其后覆盖主题，没有复制图引擎 CSS。

视频画面原来与整个播放控件一起标为 `nodrag`，因此不能从画面选择或搬动节点，缩放入口也不能正常出现。现仅播放条、替换按钮继续隔离手势；视频画面沿用图片的 React Flow 选择、移动和原 `CanvasImageResizer`。长按识别同步接受没有原生 controls 的视频正文；单次移动不展开输入参数。音频布局不在本次改动范围。
