# 超分节点设置

右上角齿轮打开轻量浮层；设置只修改当前节点，不会立刻开始超分。底部“一键启用”保持为提交入口，运行时禁止调整。配置随工程保存，重开恢复；旧工程缺少新字段时补默认值。

| 设置 | 选项与默认值 |
| --- | --- |
| 模型 | SeedVR2 3B、7B；默认7B |
| 倍数 | ×2、×3、×4、×5、×6、×7、×8；默认×2，全部整数 |
| 视频每批帧数 | 默认10；预设5、10、20、30、60，支持自定义1至120整数；图片不显示此项 |
| 种子方式 | 全部随机、固定、随机一次后共用；默认随机一次后共用 |
| 固定种子 | 0至9007199254740991整数；非法输入不会写入工程 |

全部随机表示每批重新抽取；固定表示使用输入值；随机一次后共用表示每次任务开头抽一次，该任务全部批次使用同一值。单张图片只有一次请求，后两种随机方式都在提交时抽取，不会把上一次任务随机值当作下一次任务的固定值。

每批帧数可变，每批时长仍为1秒。工作流FPS跟随批帧数，开始时间为0、1、2……。完整原视频只上传一次，每批都引用完整源；全部串行完成后按帧序拼接，恢复源FPS，再合原音轨。例如69帧、源30 FPS、每批20帧，执行20、20、20、9共四批，最终仍为69帧、30 FPS。不会先降采样丢帧。

VAE、加载、切片和超分接线沿用用户模板；只在请求副本中替换模型、倍数、种子和批次参数，不覆盖模板文件。模型名称交原模型匹配器解析实际目录；未安装所选模型时沿用原明确报错流程。

## 复用关系

- 齿轮入口与轻量浮层直接使用 `ParameterPopover`、`CanvasChip`，沿用外部点击、Escape和焦点恢复。
- 模型、倍数和种子方式直接使用 `SegmentedControl`。
- 每批帧数使用从 `VideoNumberPicker` 提取的同一个 `VideoNumberOptions`，复用预设与自定义数字输入，避免设置里再嵌套一层浮层导致裁切。
- 节点仍走原工程保存；新增共享配置校验与主进程等价校验，没有新增保存服务。

只在设置展开时放开节点外层裁切并提升层级，媒体预览仍裁切；齿轮固定为28×28，防止被压扁。浅色、深色和窄窗口都沿用画布主题。
