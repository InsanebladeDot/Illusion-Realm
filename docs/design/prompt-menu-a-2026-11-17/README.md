## 复用与边界

- 菜单继续调用 `CascadeMenu`，只增加紧凑尺寸、摘要、内容和页脚插槽，以及说明仅作提示的选项。其他菜单保留原来的默认行为。
- 从原 `CanvasSwitch` 提取 `ToggleSwitch`，画布设置仍通过原导出名使用同一个组件，转译菜单也直接调用它。
- 模型选择使用原 `AgentModelDialog`，预设编辑、历史、连接设置、提示卡片、撤销和迟到结果确认沿用原实现。
- 移除当前节点或连线图片，只从本次转译清单排除；不删除文件、资源登记或生成引用。移除额外上传图时回收其临时地址。
- 图片草稿按输入对象隔离，不写入全局偏好或文字历史。切换对象和卸载时清理临时地址，工具栏本身保持原生命周期。
- 修正联调发现的分组标题问题：再次转译 `Image N:` 多图结果时，发送端也复用原分组保护，避免标题被当成缺失资源。真正的资源标记仍由原工作流规则校验。
