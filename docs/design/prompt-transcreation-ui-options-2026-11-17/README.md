# 图片辅助转译：UI 方案

本轮只制作独立预览，没有修改应用中的菜单、状态、图片上传或生成流程。所有图中图片与标签均为演示内容。

| 方案 | 图片入口 | 如何查看图片 | 结果处理 | 适合情况 |
| --- | --- | --- | --- | --- |
| A 精简菜单 | 原转译设置菜单内 | 开启后在菜单内展开缩略图 | 沿用原输入框与撤销 | 希望尽量少改现有界面 |
| B 原位附件，推荐 | 输入框工具条中的图片开关 | 在输入框上方展开，可看到顺序和来源 | 沿用原转译和撤销 | 日常操作；能直接知道发了哪些图片 |
| C 转译面板 | 转译按钮打开旁边的轻面板 | 面板集中显示模型、预设和图片 | 先预览，再应用到输入框 | 高频识图，需要检查和比较标签 |

三个方案实际使用均默认关闭图片；主要截图展示开启状态以比较布局。B 另外提供关闭状态和浅色主题图片。

打开 [交互预览](index.html) 可切换 A/B/C、深浅主题、图片开关，添加和移除本地图片；C 可将示例标签应用到预览输入框。不发送网络请求，不访问应用数据，未选择的方案没有进入产品代码。

预览沿用当前画布的黑白表面、胶囊按钮和简洁图标。后续落地仍复用原组件：A 使用 CascadeMenu；B 使用原输入面板、附件选择和转译工具栏；C 使用原浮层与模型选择窗口。图片是否参与请求仍由同一开关控制。

验证：本地 Electron 实际渲染五个画面，均无横向页面溢出、图片缺失；检查方案切换、图片开关和演示结果应用。已查看 A/B/C 与 B 关闭状态截图。没有运行产品生成任务。
