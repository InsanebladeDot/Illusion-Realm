# 超分卡片铺满与视频首帧尺寸

超分卡片有成片后，画面铺到卡片四边；原上下白条改为画面上的模型、设置与“一键启用”控件。更换入口下移，避开设置按钮；视频启用按钮避开底部播放条。打开设置时媒体仍保留原卡片圆角。空超分节点保持原引导与提交入口，不伪装成已有素材。

普通视频与超分视频共用 `useVideoCardSize`，从现有媒体解码回调取得首次宽高，以默认宽度502、最大高度900计算显示比例。每个来源只取一次尺寸，播放时不反复调整卡片。已有手动尺寸优先，不回写媒体分辨率、生成比例或工程参数；缺少手动尺寸的卡片重开时重新读取真实素材。全局“固定所有”继续采用原默认尺寸。

缩放直接使用原 `CanvasImageResizer`、React Flow边缘与右下角控件，以及原撤销和工程保存路径；没有新增一套视频或超分缩放实现。单节点锁定与全局固定仍决定控件是否可用。普通视频卡片与超分卡片分别持有自己的首帧状态，同源副本不共享尺寸。
