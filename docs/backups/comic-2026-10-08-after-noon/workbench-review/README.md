# 漫画分镜工作台：主题与浮动窗验证

本次实现接入全局明暗主题，画布外围使用点阵背景。目录、排版属性、项目操作、尺寸模板、缩放控制支持拖动分离和固定归位；图片工具保留左右停靠及分离。窄屏默认保留中心画布，右侧固钉独立占位。

桌面端拖标题栏可分离面板，靠近该面板原停靠边缘时显示提示，松手归位；标题栏右侧按钮可直接切换浮动或固定。浮动面板会约束在工作台内，布局偏好独立保存，不混入分镜导出数据。

自检与修正记录（7 轮）：

1. 检查全局主题机制和已有颜色：定位硬编码白底，改用已有主题 token。
2. 检查布局和分离范围：接入五种外围浮动窗，保留图片工具停靠，中心画布始终挂载。
3. 类型、代码与构建检查：修正 Hook 依赖；TypeScript、Lint、静态构建与中英文键检查通过。
4. 实际明暗截图复核：修正浮动尺寸面板的宽屏三列拥挤；图片工具默认改为左侧窄工具条。
5. 真实拖动回归：发现浮动面板继承网格区域导致坐标偏移，清除浮动状态的 grid-area。
6. 五组交互回归通过 80 项检查；复核窄屏截图后，为固钉预留独立位置，并让目录与属性面板严格对齐画布行。
7. 补充触摸取消和缩屏约束；最终 6 组自动化回归全部通过，共 96 项断言。

自动化覆盖：全局主题按钮 → Electron nativeTheme → 实际 CSS 配色；五种浮动窗拖动归位；图片工具停靠、模糊、删除、恢复、原生文件选择与替换；右键菜单；自定义多边形；画布尺寸锁定；1100/950/390/320 宽度；触摸拖动取消；窗口缩小时重新约束；布局偏好重载；内容保留与 PNG 输出尺寸、白纸背景。未检测到浏览器错误或未处理的 Promise 拒绝。
