# 失败下载点 X 无法移除

日期：2026-10-27。

## 实际原因

下载失败后，removeDownload 对所有未完成任务先调用 authorizeResume；该校验要求原模型目录仍然存在。原目录已缺失时，即使模型和断点文件都不存在，操作仍抛出异常，并把任务改为 failed/io。若后续新下载重建相同目录，旧任务才可能通过检查。

本轮只读核对了用户指出的任务：状态 failed、错误 io、原目录不存在、断点不存在、模型不存在。未改写用户当前队列，也未启动或终止用户自己的客户端。

## 修复

仅修改 apps/electron/src/main/modules/models/downloads/model-download-manager.js 的移除分支：原目录不存在时直接移除任务并等待队列持久化；目录存在时继续校验配置根、realpath 和文件归属，然后清理本任务资源。

没有复建空目录、追踪被外部移走的目录或扩大删除权限。完成任务仍只删除记录并保留成品；网络失败未移除时仍保留断点以供继续下载。复用现有事件、IPC、Zustand 合并与 JSON 持久化，无需改变协议。
