# 创作区图片倍率编辑

日期：2026-10-27

图片尺寸旁的倍率支持双击编辑，默认显示 `1.0×`，确认后保留一位小数。支持 `1.x`、`2.x`、`3.x` 以及更大的正倍率；滑条默认展示 0.1–4 倍，手输更大值后延展显示范围。

- 回车或失焦确认，Esc 取消；键盘聚焦倍率后可按 Enter 或空格进入编辑。
- 空输入、负数、零和非有限值不提交，保留上次确认值；输入过程中不提前改变输出尺寸。
- 倍率保留小数，输出宽高仍是整数，并沿用图片的 8 像素对齐；不是把倍率本身取成整数。
- 例如 1344×768 在 2.1 倍下输出 2824×1616；输入 1.26 先确认到 1.3 倍，再输出 1744×1000。
- 每次以原始宽高计算，回到 1.0 倍可还原基准，不累计缩放上次结果。
- 选择新预设或修改自定义宽高仍重置为 1.0 倍；已有倍率偏好继续沿用原持久化路径。

## 复用与边界

复用 `apps/next/src/view/create/size-selector.tsx` 中的尺寸 UI 和现有 `RangeSlider`；倍率编辑在共用控件内实现，没有复制图片/视频两套 JSX。

图片适配层不传倍率上限；视频适配层传 `scaleMax={1}`，并在 `createVideoSizeSelection` 中再次限制到 1。视频继续遵守原有 64–1472 像素范围和 32 像素对齐，不能因 UI 共用而放开业务约束。

`apps/next/src/utils/imageSize.ts` 的规范化函数共同服务选择器、生成参数和 store 恢复：合法放大倍率不会在重启时被旧的 1 倍上限截断。原始尺寸、倍率和最终宽高的字段契约保持不变，shared 只同步原有字段说明。

文本输入保存局部草稿，图片/视频分别持有正式状态；两个场景切换不污染彼此。提示词同步更新 zh-CN/en。
