# 漫画分镜 Demo

## 新入口：混合分镜工作台

直接打开 [workbench-demo.html](workbench-demo.html)，离线可用，无需启动服务。这是独立 Demo，尚未接入正式工具箱，也不是需求文档全部功能的交付。

桌面为阅读目录 / 画布 / 统一设置三栏；760px 及以下改为画布 / 分镜 / 设置三个视图，保留同一选中格与同一份状态。默认五格包含横格、竖格、大小格和跨行竖格，普通格也可使用手撕相片、毛边回忆和冲击碎裂边缘。

选择「自定义排版」后，每格会获得独立的页面坐标，可在画布中拖动格子移动，拖动右下角控制点调整宽高；位置和尺寸均限制在页面内并保留 80px 最小边。选择「编辑当前形状」后，单格进入多边形编辑：拖动顶点、点击格内按最近边插入顶点，或用新增 / 删除按钮调整数量，支持 3–64 个顶点；顶点以相对格子 0–1 坐标保存，导出 PNG 时按实际形状裁切。

可以选择分镜、水平 / 垂直切格、合并空白兄弟格、调整共享边界与格间距、换模板、独立取景与放大、修改描述与旁白、换随机裂口、锁定分镜、调整阅读顺序、撤销重做、导入图片及导入 / 导出 Demo JSON、导出 1200×1600 PNG。本机草稿自动保存；导出不含选择框与阅读路径。

切格保留原格内容、新增空白格。换版式保留所有内容 ID；五格混合模板在格数不符时拒绝应用。合并仅支持直接兄弟格，另一格有图片或历史归档时拒绝，避免静默丢失素材；无图兄弟格的描述与旁白保存在 `archived` 中。共享边界操作涉及锁定格时整体拒绝。

数据使用 `illusion-realm-comic-workbench-demo` / `version: 1`，独立于正式项目格式。树形排版由切分树保存；自定义排版由 `layoutMode: "custom"` 和 `customFrames[panelId]` 保存；`panel.customVertices` 保存各格的相对多边形顶点；`order` 存阅读顺序。图片引用内置素材键或 `assets` 中的内嵌 data URI。导出还附带派生 `geometry`，导入时重新计算。单页最多 16 格、最小格宽高 80px；自选图片最大 4 MiB、8192px 单边与 1600 万像素；JSON 最大 10 MiB。不应直接拿 Demo JSON 作为正式应用落盘契约。

当前自动切格只支持水平 / 垂直矩形分区；自定义模式支持独立移动 / 缩放和每格任意多边形，但不会自动保持相邻格共享边界，也不提供多边形布尔合并。斜线共享边界与跨格覆盖尚未集成到该工作台。跨三个底格的斜切 / 撕裂覆盖请打开下方的 [prototype.html](prototype.html)。两个原型不能互相导入项目。工作台仅有旁白，没有完整气泡、竖排文字、多页、AI 生成或完整镜头预设库。

本轮仍使用同一张项目图片的裁切作为素材，验证编辑器而非新的剧情生成。验证输出在 `workbench-results/`：桌面与 320px / 390px 手机截图、`mixed-page.png`、`mixed-project.json`、`verification.json`。

复现检查：`node docs/prototypes/comic-storyboard/verify-demo-model.cjs`；浏览器检查：`node docs/prototypes/comic-storyboard/verify-workbench-demo.cjs`（独立无界面 Edge，检查交互、导入恢复、导出像素及窄屏溢出）。这是 Demo 验证，不代表正式 Electron 应用冒烟通过。

## 既有原型：相片撕裂与不规则多边形

状态：独立交互原型已完成，未接入正式工具箱。直接打开 `prototype.html`，不需要服务端。

桌面采用画布与右侧设置栏；760px 及以下切换为画布 / 设置双视图，避免压缩控制区。已验证 1440px 桌面及 390px、320px 手机宽度。

支持方向、覆盖宽度、水平位置、底格选择、隐藏覆盖格、撤销重做、阅读顺序、草稿保存恢复及 PNG / JSON 导出。阅读顺序与叠放顺序独立；选择虚线不进入导出图片。

默认采用不规则底格与相片撕裂覆盖：不等间距大缺口、长边随机走势、细碎纸边和轻微投影。三种预制风格：手撕相片、毛边回忆、冲击碎裂；点击图层选择 A / B / C / D 后，边缘样式、预设、幅度与换裂口作用于当前格，也可显式应用到全部格。覆盖宽度、方向、位置始终作用于 D。所有形状操作可撤销。底格可以切回矩形外形（仍可带裂口）；直线边缘是独立开关。目前底格基础外形是三组固定异形预设，尚不支持自由增删 / 拖动顶点。

本组使用项目原有 `anima-preview2.webp`，不生成新图片。四张分镜来自同一张原图的不同裁切，便于保持画风和人物一致；这组只验证编辑操作、裁切、图层、遮挡和导出，不用于证明新的动作生成或角色一致性能力。

| A | 野营场景全景 | 第一张底图，建立场景 |
| B | 中央人物中近景 | 第二张底图，人物反应 |

查看 `assets/contact-sheet.png`，四张独立 PNG、原始 WebP 和 `asset-manifest.json` 都保留。D 保持矩形原图，通过独立多边形裁切覆盖三个底格，不将轮廓烘焙进素材。

素材描述只说明已有画面，不将裁切包装成新画面。默认阅读顺序 A → B → D → C；叠放顺序 A → B → C → D。

`diagonal-layout.json` 带格式名和版本 3；页面尺寸使用像素，底格 frame 与导出的 overlayVertices 使用 0–1 页面坐标，底格 shape.vertices 相对于各自 frame。覆盖宽度、水平偏移和撕裂幅度使用页面像素。cropFocusY 是垂直裁切位置（0 顶端，1 底端）。每格保存 edge / preset / roughness / seed / generatorVersion；新裂口生成器为版本 2，保留版本 1 算法兼容已有草稿。保存和导出同时保留实际顶点，当前本机恢复以固定版本算法重建轮廓；正式 JSON 导入尚未实现。极值轮廓在导出前裁切到页面边界。版本 1 草稿恢复为矩形底格与直线边缘，版本 2 保留旧裂口算法和无裂口底格；另存时升级为版本 3。此格式是原型契约，不是正式项目格式。

验证产物在 `results/`：桌面 / 手机截图、1200×1600 合成 PNG、布局 JSON 和 `verification.json`。验证脚本使用独立无界面 Edge，通过 CDP 检查交互、画布像素、导出像素一致性和水平溢出。没有使用 Playwright，也不代表正式 Electron 应用冒烟通过。

本轮产物：`torn-page.png`、`torn-layout.json`、`straight-comparison.png`。此前的 `diagonal-page.png` / `diagonal-layout.json` 是上一轮斜切产物，保留供参考。

新增 `preset-photo.png` / `preset-memory.png` / `preset-impact.png`，`preset-comparison.png` 从左到右展示三种效果。联网核实的漫画排版教程、设计依据与搜索限制见 [style-references.md](style-references.md)。

复现：在仓库根目录执行 `node docs/prototypes/comic-storyboard/prepare-assets.cjs`。脚本使用当前工作区已安装的 sharp 0.34.5；不新增依赖，不修改原图。源文件引用在 manifest，裁切按源图像像素执行；脚本错误时返回非零退出码。

重建嵌入素材：`node docs/prototypes/comic-storyboard/build-prototype.cjs`。浏览器验证：`node docs/prototypes/comic-storyboard/verify-prototype.cjs`（需要允许启动 Edge）。

限制：可见面积用每格 100×100 点采样，仅计算实际多边形图像范围，不包含纸边 / 投影，也不检查人物 / 对白是否遮挡；没有生成后端、项目导入或自由顶点编辑。低分辨率原图放大后会变软。纸边与投影目前固定参数；预设效果不代表完整照片材质模拟。下一步推荐验证自由多边形与独立取景，再决定是否进入正式应用开发。
