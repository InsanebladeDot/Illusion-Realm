## 用户补充的分格功能参考

[Clip Studio 漫画分镜工具](https://www.clipstudio.net/sc/comics-manga/tool/paneling/)已读取正文。页面明确介绍划线拆框、编辑格形 / 框线粗细 / 页边距、一次编辑多个格、内置模板和保存自定义分格模板。该页面是软件功能介绍，不是网页中的可运行编辑器。

用户提供的页漫图显示横竖大小格混排、跨行竖格和明确的右读路径；环境、信件细节、人物反应与日夜变化属于叙事组织。它们补充的是完整分格与镜头关联需求，不要求全部格都做成撕裂。

据此，需求 v0.5 补入切格 / 合并 / 共享边界、模板映射、阅读路径、时间组、同图切片、基本文字与七种验收样页。此前撕裂原型仍只验证其中一部分；没有因文档扩充而自动增加正式功能。参考漫画不进入项目资产或导出示例。

## 原型预设

| 预设 | 实现方向 | 建议叙事用途 |
| --- | --- | --- |
| 手撕相片 | 长短不一的轮廓漂移、随机大小缺口、细碎毛边、白色纸芯与投影 | 拼贴、旧照片、揭示、跨格切片 |
| 毛边回忆 | 更密的细小起伏、较浅且稀疏的缺口、白色纸边 | 回忆、朦胧、时间切换；不是写实纸纤维模拟 |
| 冲击碎裂 | 间距不一的深切角口、大块折线、深色细边，少用纸张投影 | 动作冲击、预兆、破裂；不是玻璃物理模拟 |

大缺口位置、宽度、深度以及长边走势独立随机，不使用等间距三角波。每格独立保存预设和种子；只有用户点击换裂口才改变种子。默认页面 A / B / C 分别展示三种风格，D 使用手撕相片，可逐格编辑或应用到全部格。

`results/preset-comparison.png` 从左到右：手撕相片、毛边回忆、冲击碎裂。该图由原型画布导出并拼接，不是网页截图或网络漫画资产。

限制：尚未支持指定某条边撕裂、裂口手工定位、自由顶点和图像独立取景。形状仍服务现有跨三格原型，不代表完整模板库。人物 / 对白保护仍需人工检查。
