# C站本地已有标记：严格名称与已有 SHA256

## 本轮规则

按用户最终确认执行，名称优先，摘要回退：

1. 本地模型实际文件夹末段与 C站模型标题完全一致，并且同一文件夹内某个模型文件去权重扩展名后的完整主干，与远端某个文件的完整主干一致，则显示“本地已有同名文件”。不要求本地 JSON 存在。
2. 名称条件不满足时，仅使用本地 `<模型文件>.civitai.json` 中已保存的完整 SHA256，与远端文件 SHA256 比较。一致则显示“本地已有相同文件”。
3. 缺 JSON、来源不可读、摘要为空、格式非法或摘要不同，均不据此显示已有。名称分支独立有效。
4. 标记判断不读取权重内容、不计算模型 SHA256、不自动补全资料。显式单项/批量补全仍使用原流程。

名称保留大小写、版本、精度、空格和标点；不采用模糊包含匹配。去掉的只是最后一个已识别权重扩展名。哈希要求完整 64 位十六进制，其大小写不影响比较。任一已返回版本文件命中即可提示此模型存在对应本地项，不表示全部版本已下载。

名称提示不证明文件内容一致；摘要提示只比较已有记录，不承诺文件被外部覆盖后仍与旧记录一致。两个提示的悬停说明均明确证据边界。

## 修改与复用

| 文件 | 本轮职责 |
| --- | --- |
| `apps/next/src/utils/civitai-local-models.ts` | 将全库文件名集合改为目录标题与文件主干的配对索引；提供已有摘要索引和分支判定。原分类计算保留。 |
| `apps/next/src/view/toolBox/Tool/civitai/civitai-page.tsx` | 用设置中的同一扫描结果构建名称证据；复用 `useLocalModelMetadata` 批量读取既有来源，所有卡片共享索引。 |
| `apps/next/src/view/toolBox/Tool/civitai/civitai-card.tsx` | 向原 `ModelLibraryCard` 的角标插槽注入证据类型，保持原选择和详情行为。 |
| `apps/next/src/i18n/locales/{zh-CN,en}/toolBox.ts` | 分开名称与摘要提示及悬停说明。 |
| `scripts/smoke-model-source.js` | 在原模型来源回归中增加六个真实临时磁盘样本和零补全调用断言。 |

没有新增 IPC、存储层、扫描器或卡片组件。只有当前远端结果存在名称未命中项时才需要读取来源 JSON；没有远端结果或全部严格同名时跳过读取。相同本地路径与扫描版本下，分页、选中或切换网格不会重复请求来源。下载、补全后的重新扫描会使来源更新；用户手工修改来源后需重新扫描或重新进入在线页。

读取复用既有每批 200 项、主进程并发 8 项、单份来源 2 MiB 上限与路径授权。会对权重路径做存在性及真实路径检查，但不读取权重字节。加载或失败时不拿旧摘要继续显示成功角标，远端浏览和下载仍可使用。
