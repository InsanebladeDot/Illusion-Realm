# C站本地模型 SHA256 匹配修复

2026-11-15。仅调整在线模型库的本地匹配与手动补摘要，保留本轮之前的工作区修改，没有提交或上传 GitHub。

## 现在如何使用

进入工具箱 → C站模型。顶部点「加载 SHA256」，查看说明后点「开始计算」。处理范围为设置中已经扫描到的模型版本文件，逐个处理、显示各文件结果；已有完整摘要直接跳过。点「停止后续」、关闭弹窗或离开页面，当前文件安全完成后停止剩余项。计算过程不联网，不需要 C站 API Key。

只比较完整64位十六进制 SHA256。文件名、文件夹名、模型标题均不参与身份判定；同名不同摘要不匹配，改名但摘要相同仍匹配。遍历接口已经返回的所有版本与文件，任意一份命中即标「至少一个版本已匹配」。不会为了角标逐个联网补查远端尚未返回的版本，也不声称所有版本已安装。

## 文件与兼容

已有 `<权重文件>.civitai.json` 的有效 SHA256 可直接用于匹配，浏览列表不会重新读权重。缺少摘要时，复用已有流式 SHA256 计算器，固定1MiB缓冲；本入口最多两个并发请求，页面队列串行。

新摘要放在同目录的 `<权重文件>.sha256.json`，例如：

```text
model.safetensors
model.safetensors.civitai.json   原来源资料，保持原样
model.safetensors.sha256.json   新离线摘要及文件状态
```

独立摘要文件避免伪造 C站来源资料，也不会让原来的「补全资料」功能把只有摘要的文件误认作资料齐全。按文件隔离，同文件夹多个版本不共用摘要。文件大小、时间、inode/dev变化会使离线记录失效；这时不回退到旧来源摘要，需要重新计算。旧来源JSON没有文件状态记录，继续按既有保存摘要使用，不宣称它是本轮重新校验的结果。

JSON写入临时文件后再提交，保留未知字段；拒绝损坏或未来版本的摘要JSON，不覆盖原来源、触发词与封面。路径授权、目录锁、模型前后状态复核和文件句柄清理复用现有主进程能力。摘要失败逐文件显示原因，不删除权重。
