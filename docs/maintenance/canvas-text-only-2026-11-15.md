# 文生图不使用参考图片

画布文生图参数区隐藏参考图导入入口、直接导入的缩略图及连线图片，`@` 不提供资源引用；即使保存过自定义标记，也不把普通文字转换成图片引用。

已保存的附件和连线保留在工程中，切回图片编辑后可继续使用。本地和非本地文生图的实际生成请求均不上传这些输入图片。新建图片连线仍遵守原零图片规则；保存和恢复允许保留切换模式前的图片边，重复连线、类型及循环校验继续执行。

沿用原 `CanvasReferenceInputs`、`ImageReferencePrompt` 和提示词浮层，没有复制组件或新增样式。展示、引用及请求通过同一文生图判定保持一致。
