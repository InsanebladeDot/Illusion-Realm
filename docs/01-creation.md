# 创作流程与提示词

用户希望在同一页面整理提示词、选择模型、生成图片，并从历史结果继续二创。

- 按可用主区宽度分栏。窄窗资源页打开时，保留原工作区、草稿和任务订阅，关闭后恢复原视图。
- 提示词支持分组、排序、快捷词、翻译历史和素材引用。生成参数支持尺寸、蒙版和倍率，模型选择沿用本地模型库。
- 图片任务串行执行，分别支持移除排队任务、停止当前任务和停止全部任务。断连时终止待执行任务并保留已写入的媒体。
- 历史图片可以排序、重命名、移动和收藏。二创从对应图片读取 PNG Meta 和原 API 工作流。
- 图像配方处于规划阶段。首版支持可识别的 Anima 和 SDXL 文生图，保存源图对应的真实 API 工作流、模型、LoRA 双权重及采样参数。应用时保留当前提示词，需由用户另行提交生成。

## 生成任务生命周期

- 提交时冻结参数和输出目录。切换页面时保留任务，图片队列按 FIFO 串行处理，重启后需手动重新提交。
- 取消排队仅撤回本应用尚未提交的任务。停止运行任务须核对远端任务 ID，并等待队列确认。停止全部只处理本应用任务。已写入的图片与已完成张数保留。
- 单个工作流报错后可继续下一项。连接断开、等待超时或远端停止无法确认时，终止待执行任务并提示用户检查服务端队列。共享服务中核对与中断是两个请求。

## 配方格式模板

配方用本地 JSON 存储，封面单独保存。以下是空配方库模板。每条记录使用稳定 ID、时间、模型适配器版本、源工作流和提示词绑定。保存时清除正负提示词及封面的相关元数据。导入时校验引用、循环、资源路径与支持的节点类型，再按原参数回填。

```json
{"format":"illusion-realm.image-recipes","version":1,"items":[]}
```
