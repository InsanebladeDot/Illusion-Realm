# Illusion Studio 轻量化音视频剪辑模块需求文档

版本：V1.1 修订提案｜日期：2026-10-26｜依据：V1.0 需求文档及两份深浅主题概念图

本版用于生成下一轮 UI 概念稿与确定首版边界，描述的是目标能力，不代表现有功能已经实现。“Illusion Studio”沿用概念稿名称；接入 Illusion Realm 时使用现有品牌配置，不据此重命名整个产品。

## 1. 产品定位

面向 AI 创作和二次元短视频制作的桌面剪辑工具。核心任务：把几段视频、图片、角色配音和背景音乐编排成一条可保存、可预览、可导出的短片。

轻量化体现在默认界面简单、常用操作直接、后台处理有边界。专业布局用于帮助理解剪辑，不以专业软件的面板数量作为设计目标。

核心闭环：**新建项目 → 导入素材 → 放入时间轴 → 剪辑与配音 → 预览 → 保存 → 导出。**

典型用户不需要先学习源监视器、轨道目标、关键帧曲线或混音台，才能完成第一条视频。

## 2. 本次修订的关键决定

| 项目 | V1.1 决定 |
| --- | --- |
| 默认监视器 | 一个较大的节目预览；素材查看按需切换，双监视器属于后续可选布局 |
| 深浅主题 | 同一布局、组件、数据和操作状态，只改变主题色与表面层级 |
| 首版剪辑 | 多轨基本编排、移动、切分、修剪、复制、删除、固定速度与基本音频 |
| 空隙与重叠 | 保留空隙；同轨禁止时间重叠，跨轨允许并按明确规则合成 |
| 转场 | 首版直接切换、片段淡入/淡出；片段间交叉溶解后续实现 |
| 字幕与曲线 | 后续功能，首版概念稿不显示字幕轨、速度曲线或相应占位标签 |
| 模块接入 | 复用当前工具路由、应用外壳和 FFmpeg 基础能力，不建立第二套桌面应用 |

## 3. 首版范围

### 3.1 首版必须完成

- 项目创建、保存、另存为、打开、未保存提醒、基本异常恢复及丢失素材重新定位。
- 批量导入视频、音频、图片；媒体探测、逐文件错误、缩略图与真实波形。
- 一个节目预览；素材单独查看、播放并添加完整素材，不强制先设置入点/出点。
- 多视频轨与多音频轨；默认显示 V1、A1、A2，按需新增轨道。
- 片段移动、跨同类轨道移动、两端修剪、播放头切分、复制、删除、基础多选与撤销/重做。
- 吸附开关、时间轴缩放/滚动、播放头定位、播放与逐帧检查。
- 视频/图片的基本缩放、位置、单一二维旋转与不透明度；图片的默认显示时长可修改。
- 固定速度、片段音量、音频淡入/淡出、视频淡入/淡出及轨道锁定/可见/静音/独奏。
- 视频内嵌音频与画面的链接移动和编辑；可解除链接后独立处理。
- PNG/JPEG 节目帧导出、MP4 视频导出、WAV 混音导出及任务进度、取消、失败反馈。
- 基础缓存、预览能力探测与必要代理策略；这些是首版可用性的组成部分。

验收基线至少覆盖同时使用 2 条视频轨、4 条音频轨的项目。界面不预铺所有空轨，也不把轨道数写死为基线数量；超出已验证负载时给出明确提示。

### 3.2 后续版本，不作为本轮概念稿内容

| 阶段 | 能力 |
| --- | --- |
| 第二阶段 | 可选双监视器、素材入出点插入、交叉溶解、波纹删除、框选与批量编辑增强、轨道音量、导出队列 |
| 第三阶段 | 动态变速曲线、音量关键帧、字幕/文字轨、角色与 CV 台词管理、AI 人声分离、复杂效果 |

首版不展示“效果 / 音频 / 字幕”整排空标签，不出现关键帧菱形、曲线编辑器、专业混音台或未实现的 AI 按钮。音频片段所需属性直接在统一属性区显示。

## 4. 工作区与视觉要求

### 4.1 默认结构

| 区域 | 展示内容 | 交互边界 |
| --- | --- | --- |
| 顶部工作栏 | 项目名、保存状态、文件/编辑/视图、撤销/重做、导出 | 与宿主标题栏协调，只保留一套窗口控制 |
| 左侧素材区 | 导入、搜索、全部/视频/音频/图片筛选、紧凑素材列表 | 分类树按需展开，不默认占据第二列 |
| 中央节目预览 | 当前最终画面、时间码、播放、逐帧、适应、导出当前帧 | 默认最大可用展示面积，维持项目宽高比 |
| 右侧属性区 | 当前选中对象的名称与可用参数 | 可折叠，避免展示与对象无关的参数 |
| 底部时间轴 | 轨道头、片段、刻度、播放头、精简工具栏 | 操作主区域，允许调整高度与轨道滚动 |

窗口外壳沿用项目现有实现。概念图未画到的全局导航不构成删除导航的授权；落地时由现有工具页容器提供主区，不在编辑器内部再创建 AppShell、系统标题栏或窗口控制按钮。

### 4.2 尺寸与收缩

- 概念稿基准画布为 1600 × 1000，展示编辑器专注工作区；概念尺寸不是应用窗口最小尺寸承诺。
- 左侧素材区参考宽 240–260px，属性区参考宽 260–280px，中央预览占剩余宽度。
- 时间轴默认约占可用内容高度的 40%–45%；上下分隔线可拖动，保证预览和轨道操作区各自可用。
- 实现按编辑器容器的实际宽度调整，不沿用创建页的 760/1040 断点。约 1280px 以下允许属性区临时展开；更窄时素材区也可折叠。
- 收缩时保留节目预览、时间轴与导出入口。打开临时面板不应覆盖正在修剪的片段或播放控制；提供关闭和恢复布局入口。
- 在实际宿主最小窗口、系统缩放和 nav 开合下验证；不能用整体缩放界面解决拥挤。

### 4.3 深浅主题

- 两份概念稿使用完全相同的面板位置、片段、选中状态、时间码、文本与按钮。先确定一份布局，再生成同布局主题变体。
- 浅色：冷中性色表面、明确的深色正文、蓝紫强调；避免整屏泛白、低对比淡蓝文字。
- 深色：中性深灰或蓝灰表面、清晰正文与边界；避免大面积发光、暗灰文字和过多纯黑。
- 视频片段用蓝色系，音频用青绿色系；选中对象以边框、手柄和名称共同表示，不能仅靠颜色。
- 预览画面外的留边保持中性深色，避免主题装饰干扰视频判断；波形、刻度和选中边界优先可读。
- 二次元元素放在用户素材缩略图和预览画面中；不用大幅角色立绘、花瓣或插画铺满操作区域。
- 实现时普通文字对比度目标至少 4.5:1，关键控件与焦点边界至少 3:1；截图观感不能代替测量。

### 4.4 简化控件

- 时间轴工具栏保留：选择、切分、吸附、链接选择、添加轨道、缩放与适合全部。图标提供文字提示和快捷键说明。
- 轨道头按类型显示有效控制：视频为可见/锁定，音频为静音/独奏/锁定；音量表在播放时按需显示为紧凑状态，不常驻占一整列。
- 视频属性只显示缩放（默认等比联动）、X/Y 位置、一个二维旋转值、不透明度、固定速度和淡入/淡出。
- 音频属性显示素材信息、音量与淡入/淡出；视频属性不重复渲染独立音频轨道的参数。
- 单帧导出放在节目预览旁，视频/混音导出放在顶部导出入口；输出路径不常驻占据属性区。

## 5. 选择、焦点与素材查看

- 素材库选择与时间轴选择分别保存；属性区只跟随时间轴片段或项目选择，标题明确“片段属性 · scene_02.mp4”。
- 单击素材选中；双击或点击“查看”在中央区域临时切换到素材预览，并醒目标注“素材查看”。返回节目预览后恢复时间轴播放头。
- 素材查看不更改时间轴、不作为节目帧导出来源；音频素材展示波形和播放控制，不显示无说明的角色视频。
- 素材查看与节目播放互斥，切换时停止另一方，不能同时响两套声音。首版不要求并排双监视器。
- 空格和方向键作用于有焦点的监视器或时间轴；文本输入时不触发剪辑快捷键。
- Delete 只操作当前活动区域的对象。移除素材库引用与删除时间轴片段是不同操作；不删除磁盘原文件。
- 多选时显示公共参数与混合值；无选中时显示项目设置。锁定对象不能被修改。
- 键盘路径覆盖导入、选择、播放、切分、删除、撤销与关闭面板；焦点可见并在关闭临时面板后返回原入口。

## 6. 时间轴语义

### 6.1 时间、空隙与合成

- 项目帧率为有理数时间基准，视频片段以整数帧记录时间轴位置；音频内部保留采样精度并明确与视频时间基准的换算。
- 首版新建支持 24/25/30fps，默认 1920 × 1080、30fps、48kHz。导入不同帧率和可变帧率素材时按时间戳映射，不直接将源帧号当项目帧号。
- 首版在已有片段后冻结项目帧率；分辨率与横竖画幅可修改，确认时说明按归一化位置/相对缩放保持构图。素材排序不改变项目输出设置。
- 区间统一为起点包含、终点不包含；片段移动和修剪不会隐式改变别人的位置。
- 空隙真实存在。没有可见视频时输出黑场，没有音频时输出静音；不自动跳过或关闭空隙。
- 同一轨道不允许时间重叠。拖动、修剪、粘贴或变速产生碰撞时显示无效落点并拒绝提交，保留原状态。
- 不同视频轨道可在时间上重叠，上层按图层顺序和不透明度合成；不同音频轨道同时混音。
- 首版支持的重叠是跨轨重叠，不自动生成转场；不提供隐式覆盖剪辑或自动推开后续片段。
- 吸附只帮助对齐播放头、片段边缘和项目起点，不能移动其他片段。提供开关与临时绕过操作。

### 6.2 拖动、切分与音画链接

- 外部文件拖入素材区后先探测；加入时间轴显示目标轨道、起止时间和有效落点，失败不留下半成品片段。
- 视频默认将画面与内嵌音频创建为链接的 V/A 片段。没有音频流的视频不创建虚假音频片段；图片默认时长 5 秒。
- 同一次链接操作中的移动、修剪、切分、复制、删除和固定变速共同生效；所有目标通过校验后一次提交，任一碰撞或锁定则整组拒绝。
- 解除链接后允许独立移动；重新链接不自动对齐或改变时间，不在首版提供自动找同步点。
- 修剪改变使用的源区间，不超出源素材范围；切分保留前后源区间与效果，不重置缩放、速度或音量。
- 删除保留空隙；复制保留原段，粘贴在播放头并遵守轨道兼容、锁定及碰撞规则。
- 拖动过程中只呈现草稿；松手提交一次撤销记录，取消恢复原值。属性拖动和数值输入也按一次完成操作合并撤销。

### 6.3 速度与淡入淡出

- 固定速度提供 0.5×、1×、1.5×、2× 及范围 0.25×–4× 的数值输入。改变速度保持时间轴起点与源区间，重新计算时长并验证碰撞。
- 链接音频采用相同时间映射，默认保持音高；实现必须验证处理链支持范围，不能用音频静音掩盖不同步。
- 视频淡入/淡出调整片段边缘不透明度，音频淡入/淡出调整增益；均不移动片段，不改变项目时长。
- 淡入淡出长度受片段长度限制，不出现两端区间互相越过。空隙默认黑场时，视频淡出体现为淡到黑。
- 交叉溶解需要双侧源余量与独立关系规则，延至后续，不在首版伪装为可用。

## 7. 素材、预览与缓存

- 支持范围按实际媒体流和探测结果确定；MP4/MOV/WebM、WAV/MP3/M4A/FLAC、PNG/JPEG/WebP 是候选输入类别，不保证每种内部编码都可直接预览。
- FFmpeg 能解码不等于 Electron 能直接播放。导入后区分可直接预览、需要代理、不可用三类，并展示下一步。
- 媒体探测、缩略图、波形、代理和导出均可报告状态；单文件失败不影响其他导入。静态图片不伪造媒体时长或波形。
- 预览与导出共享片段顺序、时间映射、合成和音频规则，允许低分辨率预览，不允许缺失图层、不同速度或错误声音。
- 播放采用统一时钟与多音轨调度；拖动播放头采用最新请求优先，取消或丢弃过期结果，不能播放旧 seek 返回的画面。
- 拖动中可降低清晰度；停止后收敛到精确目标。解码未就绪时显示加载状态，不将停留的旧帧当成当前帧。
- 缩略图/波形按需生成并缓存，代理仅对需要的素材生成；设缓存容量、清理和内容变化失效机制。
- 缓存丢失可重建，不影响项目数据；关闭项目释放解码器、音频节点、对象 URL、监听和所属任务。
- 精确帧检查与节目帧导出不能仅依赖浏览器近似 seek 的结果，须验证实际画面与目标时间。

## 8. 项目保存与导出

### 8.1 项目文件

- 项目独立使用带 schemaVersion 的 JSON 文件；包含项目设置、素材引用、轨道、片段、链接组和已支持参数，使用稳定 ID。
- 用户偏好仍沿用现有用户数据文档；不能把整个剪辑项目塞进全局设置，也不因剪辑器引入另一套账号或存储框架。
- 素材默认只引用路径，原文件只读。失效引用可重新定位；替换时核对流和时长，不静默绑定到不同文件。
- 保存采用临时文件与原子替换，保留最近有效版本。自动恢复记录单独保存，恢复前明确提示，不覆盖手动保存的项目。
- 素材丢失仍可打开与保存项目，受影响片段显示明确缺失占位；需要这些素材的播放区间不冒充正常画面，导出前阻止并列出缺失项。
- 未保存修改、后台任务和恢复记录在关闭时分别处理；删除素材引用不删除磁盘文件。被时间轴使用的素材不能静默移除。

### 8.2 导出

- MP4 默认 H.264 + AAC，WAV 导出混音；以已集成工具能力为准，提供格式、项目分辨率/帧率、质量预设、文件名、目录与范围。
- 默认导出从 0 到项目最后一个片段终点，包含中间空隙；指定范围为起点包含、终点不包含。范围不含任何可导出内容时提示用户。
- 导出确认时创建固定项目快照；此后继续编辑不改变该任务，界面标明“导出开始时的版本”。首版同时运行一个导出任务。
- 单帧导出使用节目时间与项目分辨率，包含已支持的合成效果；不得导出素材查看画面或低清预览缓存。
- 指定时间必须落在项目可导出的帧范围内；黑场可导出为黑色图片，预览主题不改变黑场颜色。
- 导出前检查编码能力、素材、输出目录与冲突；默认自动避让重名，替换必须由用户明确选择，不覆盖输入素材。
- 进度来源于实际任务；未知剩余时间不伪造数字。失败显示可理解原因并允许重试；取消终止进程并清理本任务临时产物。
- 写入临时输出，完成校验后发布最终文件；出错不留下看似成功的目标文件。完成后可播放结果或打开所在目录。

## 9. 接入与验证

当前项目已经有 `apps/next/src/app/tools/video/editor/page.tsx`、`apps/next/src/components/videoEdit/`、`apps/next/src/utils/video/` 和 `apps/electron/src/main/modules/ffmpeg/`。实现前核对实际能力与调用方，复用文件选择、媒体探测、进度、取消和输出路径机制。

现有列表拼接与新自由时间轴的语义不同，不把旧 concat 参数改名后当作多轨引擎；不破坏视频/GIF 共用能力。新增剪辑状态、时间模型和合成规则应有清楚边界，跨进程类型放 shared，OS/文件/FFmpeg 放主进程，渲染层经 preload 调用。

先做预览与导出的技术验证，再完成完整工作区。验证项目包含两个视频、一张透明图片、两条音轨、空隙、切分、固定变速、链接移动和一处淡出；通过后再扩展体验，不用静态波形或模拟进度代替实现。

| 验收项 | 必须观察到的结果 |
| --- | --- |
| 数据闭环 | 保存、关闭、重开后片段位置、源区间、链接和参数一致 |
| 时间轴 | 删除保留空隙，同轨碰撞拒绝，跨轨合成正确，缩放不改变项目时间 |
| 音画联动 | 链接移动/切分/变速一致，非法整组操作不出现部分成功 |
| 播放与导出 | 选定项目帧画面对应，多音轨同步；黑场、固定速度及淡入淡出一致 |
| 异常与资源 | 损坏、缺失、代理失败、磁盘不足、取消均可恢复；关闭后资源与进程释放 |
| 交互 | 焦点、文本输入、多选、锁定、撤销/重做及面板开合不误操作 |
| 主题与布局 | 同一项目深浅主题布局一致，窄窗口与系统缩放不遮挡核心操作 |

性能基线在编码前选定一台目标设备，并记录 CPU/GPU/内存、编码、分辨率、时长、片段/轨道数；测导入到可操作时间、拖动响应、seek 收敛、播放丢帧、内存和取消耗时。用首轮结果确定并冻结后续验收阈值，未测前不承诺任意设备实时满帧。
