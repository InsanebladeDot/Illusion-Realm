# Agent、模型与下载

用户希望按价格与图片输入能力选择供应商模型，在同一工作台管理本地模型、依赖和下载。

- Agent 和提示词转译共用模型目录及选择组件。选择确认后才切换当前模型。图片输入、提示词引用和流式响应由模型能力和当前运行共同约束。
- Electron 按需启动 Python Agent，前端接收带 `runId` 的事件。供应商凭据由主进程管理，宿主工具按能力和用户权限调用。
- 本地库支持分类、封面、目录及 SHA256 匹配。工作流清单按真实依赖分组，资源进队前去重，失败可重试，下载恢复后按落盘文件重新核对可用性。

## Agent 接入与权限边界

Electron 校验请求、管理运行与停止时机。`runId` 标识一次运行，宿主调用 ID 将请求和响应配对。主进程直接处理具备完整上下文的只读工具。需要创作草稿或队列的工具由主进程转给既有工作流。凭据由主进程专用服务读取并注入子进程，页面只查询配置摘要。

## 消息与模型查询模板

```jsonc
// 渲染层发起 agent:run，字段以共享类型为准。
{"question":"整理画面提示词","history":[],"config":{"permission":"readonly"}}
```

Python stdout 输出逐行 JSON 事件。主进程按运行转发 `answer_delta`、工具事件、`final` 和 `error`。取消后忽略迟到事件，页面在结束或卸载时释放订阅。

模型查询先按类别、系列和关键词筛选可用主模型，再用完整相对名称查询兼容 LoRA。相对名称包含子目录及真实扩展名。提交前再次核对本地和 ComfyUI 清单。角色检索优先使用本地四属性数据，姓名和作品严格唯一匹配时可补充在线详情。
