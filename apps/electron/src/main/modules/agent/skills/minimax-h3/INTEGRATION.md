# Illusion Realm 接入说明

本目录来自用户指定的 `D:\prompt\minimaxH3\skills` 本地快照，导入日期为 2026-10-24。上游链接：[MiniMax-AI/MiniMax-H3](https://github.com/MiniMax-AI/MiniMax-H3)。保留 41 个源文件的原始字节；`manifest.json` 登记十个技能、默认入口、附属资源及 SHA-256。本文与清单为项目接入文件，不属于上游原文。

## Agent 使用路径

1. 普通“怎么写、能做什么、给个示例”等咨询直接使用应用维护的 H3 基础速记回答，不强制查询技能目录，不执行生成。
2. 确实需要更精确的资料时，已知技能直接使用 `read_agent_skill`。H3 通用规范为 `h3-prompt-writing`；基础/首尾帧模式可直接读取 `references/base-en.txt`，Ref2VA 可直接读取 `references/ref-en.txt`，不必先列目录或读取入口正文。
3. 未知技能才用 `list_agent_skills` 查询名称、说明与原始 compatibility，采用短关键词；一次无结果可用无筛选目录定位，避免反复用长句查询。
4. 只读取任务需要的内容，长文件确需续读时使用 nextOffset；不能把局部阅读说成全文已读。默认四轮包含最后一次回答，最后一轮禁用新工具调用，依据已有资料回答或说明缺失。
5. 动漫任务确有需要时可组合 `anime-director`；其他风格按需选择，不为简单动作示例遍历无关技能。简单咨询的两次资料调用是模型指导，执行器的硬限制仍是总轮次、工具预算及最后一轮禁用工具。

两项工具由现有宿主桥转发，不依赖 Python 的用户目录白名单，也不开放任意磁盘文件读取。资源跟随 `agent/**/*` 放入 app.asar，开发和安装后均从模块旁读取，无需原始 D 盘目录。

## 实际能力

提示词写作与动漫导演两项上游技能声明可移植；其余八项声明依赖 MiniMax Hub 的画布或专用工具。这里保留原文及兼容性说明，可复用其创作流程和输出规范。

读取文档不会自动注册 `hub_*`、视频生成、配音、拼接或画布能力。当前 Agent 的 `generate_image` 是 Anima/SDXL 图片工具。没有真实视频执行工具时，Agent 应交付 H3 提示词、分镜或制作方案，并说明尚未执行视频生成。项目现有的视频页面工作流不会因为导入技能就自动变成 Agent 工具。
