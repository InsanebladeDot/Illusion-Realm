# SDXL image generation

One SDXL checkpoint includes CLIP and VAE. LoRAs are optional.

## Download and select a main model

Use the [Civitai model library](/tools/models/civitai) to keep model version metadata together. Automatic download provides SDXL 1.0 base. Switch to SDXL and select the downloaded file in Create; your existing selection is not replaced.
