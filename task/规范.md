# TS + Next.js + Electron 最小最简开发规范

本规范旨在为 `TypeScript + Next.js + Electron` 桌面端应用提供一套轻量、清晰、可执行的开发标准，确保主进程与渲染进程隔离，代码结构高内聚低耦合。

## 一、 目录与文件结构规范

严格遵循以下目录划分，保持项目结构清晰：

```text
src/
├── app/      # Next.js 路由与页面入口 (仅包含路由文件，业务逻辑抽离)
├── view/                 # 【规范1】页面级组件与视图文件 (对应具体页面的 UI 实现)
├── components/           # 全局通用 UI 组件 (Button, Modal, Card 等)
├── utils/                # 【规范2】辅助函数、纯计算逻辑、工具类 (严禁包含 UI 逻辑)
├── stores/               # 【规范3】本地持久化数据与全局状态管理 (如 Zustand/Pinia)
├── types/                # 【规范4】TypeScript 类型/接口定义 (按模块划分 .d.ts 或 .ts)
├── data/                 # 【规范5】静态化数据、常量配置、Mock 数据、ComfyUI 工作流 JSON
├── assets/               # 【规范6】不变的本地静态资源 (图片、视频、SVG icon、字体)
├── electron/             # Electron 主进程代码 (Main process)
│   ├── main.ts           # 主进程入口
│   ├── preload.ts        # 预加载脚本 (暴露安全 API 给渲染进程)
│   └── ipc/              # IPC 通信处理器
└── styles/               # 全局样式
