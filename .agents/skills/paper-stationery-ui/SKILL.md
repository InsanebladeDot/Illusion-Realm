# 纸品与文具风格 UI（可选）

## 使用定位

这是风格推荐库。结合当前内容选择合适的纸品形式；用户有明确设计时优先按其设计实现。不因读取本技能就统一改造页面，不向 AGENTS.md 或开发门禁加入强制引用。

风格参考 Ephemera 的 Paper UI：把纸张、墨迹、印刷和文具的特征用于界面。票券偏印刷，便签可以偏手写，账本偏规整排版；它们可以共享视觉语言，不必都使用手写字。

## 按内容选形式

| 内容 | 推荐形式 | 主要特征 |
| --- | --- | --- |
| 任务清单、下载指南 | 索引卡、手账页 | 细边线、清晰标题、可选横线、勾选项 |
| 提示词预设、创作灵感、分镜备注 | 便签 | 柔和纸色，可选胶带、卷角或轻微倾斜 |
| 生成完成摘要、任务记录 | 票券、小票 | 编号、分区、虚线或打孔，等宽数字 |
| 分类、来源、状态 | 标签 | 简短文字、墨色边缘、局部强调色 |
| 收藏或内容摘要 | 索引卡 | 内容、说明与操作区域分明，装饰克制 |

模型选择、密集参数、媒体预览、画布背景和全局导航优先保持现有功能布局；确有设计需求时再局部使用这种风格。

## 统一视觉语言

- 用纸面色、墨色、边线、横线和少量强调色建立层次。示例方向：奶油纸、牛皮纸、浅绿账本、深色炭纸；跟随应用明暗主题选择。
- 以细边、小圆角、浅投影表现纸片厚度；颗粒纹理保持轻微，文字区域应清楚。避免每张卡都堆叠胶带、印章、卷角。
- Ticket 可采用主体与票根、半圆缺口、打孔虚线和序列号；这些特征按内容取舍，不必复刻全部装饰。
- Sticky Note 可使用小角度倾斜与卷角；长文本、表单和密集列表优先摆正，避免影响阅读与点击。
- 标题可用衬线字体，编号可用等宽字体，短备注可用手写字体。先检查中文覆盖，正文沿用可读字体；拉丁手写字体不代表支持中文手写。
- 动效表达按压、揭开或轻微抬起即可，尊重减少动态效果的系统设置。票根撕除等视觉动作不直接等同于删除业务数据。

## 在本项目中落地

1. 先查看目标区域与现有 Card、弹窗、按钮、提示组件。能用外观参数、插槽和回调表达差异时，复用现有组件与行为。
2. 将纸张、墨色、边线等变量限定在局部容器内，再映射应用语义色。保留现有主题机制，不覆盖全局控件变量。
3. 装饰层不拦截输入或点击，不裁切弹出内容；交互区域、键盘操作和焦点辨识保持可用。
4. 验证明暗主题、窄宽度、长中文与实际内容；纸色、纹理、倾斜和阴影以可读性为准调整。

Ephemera 的整套主题安装会合并全局 CSS，并修改通用组件变量。仅参考风格时无需安装整套库，也无需引入外部运行时字体。实际需要复制源码时先核对依赖，并保留 MIT 许可要求的声明。
